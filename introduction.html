图随我意：从绘图代码到可视编辑

简体中文 · English

README · 安装 · 完整教程

科研改图常常需要反复调整坐标框、标题、图例、字号和子图布局。图随我意保留源码与数据，把这些修改放进本地浏览器工作台，并把最终设置带回代码。

下面七个 GIF 来自实际工作台操作。先完成快速安装，再使用合成 CSV 示例尝试；熟悉后，将同样流程用于自己的源码。普通 SVG 与原生语义图的编辑能力不同，见文末说明。

1. 缩放坐标框

目标：改变绘图区长宽，同时保持数值含义。

  1. 左侧选中单图；组图先进入要编辑的子图。
  2. 切换到“坐标框”层，选中绘图区。
  3. 拖动四边或四角手柄；左右改宽，上下改高。也可在右栏输入尺寸。
  4. 查看数据、误差线、刻度与坐标框一起重新映射；只改尺寸，不改观测值。

GIF 刻意展示较大幅度的变化。组图联动使用坐标框的实际宽高，不是把整个图片容器强制成同样大小。固定比例地图、极坐标和 3D 等特殊布局按适用方式调整；不以拉伸地图代替改变投影。

需要更大编辑区域时，可拖动左右侧栏的内侧边缘。预览缩放只改变屏幕显示，不改变输出尺寸。

2. 选择坐标范围与主刻度

目标：决定观察区间，以及轴上显示哪些数值。

  1. 在原生坐标图上右键坐标轴，打开范围编辑侧栏。
  2. 选择 X / Y，输入下限与上限，直接观察预览。
  3. 用主刻度定位（major tick locator）设置间隔、数量或自定义位置。
  4. 核对关联组件后应用，需要时撤销。

范围为 0–10 时：

目标刻度设置方式
0、5、10主刻度间隔 5，或自定义位置
0、2、4、6、8、10主刻度间隔 2，或含两端的 6 个主刻度
不等间距的指定值自定义主刻度位置

同一侧栏提供 linear、ln、log₂、log₁₀ 等尺度。对数尺度使用大于 0 的数据与范围，显示尺度不改写原始输入。离散轴可以调整标签样式与角度，不把类别当连续数值重算。

3. 移动与缩放图例

目标：图例清楚，同时不遮住数据。

  1. 切换到“图例与色标”，点击图例整体，拖到合适位置。
  2. 拖外框手柄等比例缩放，符号、文字与边框一起变化。
  3. 双击图例，在固定右栏中调整方向、行列、条目顺序、符号与文字间距。
  4. 修改分类颜色时选择相应系列 / 适用范围，核对数据系列同步更新。

连续色标的编辑器提供渐变节点、颜色、尺寸与刻度等适用参数。图例内部排版和整张图例的位置可分别修改。只改误差线颜色时进入误差层，保留它与数据主体的位置关联。

4. 精修子图字体与色标

目标：统一共同格式，保留各子图的独立内容。

  1. 左侧勾选至少两张单图，创建组图；按提示先编辑子图，再查看完整组图。
  2. 保持“本组联动修改”开启，修改兼容共同格式；GIF 中两张图字号一起更新。
  3. 从子图列表选择另一张，单独调整连续色带、色标刻度字号与尺寸。
  4. 对需要保留独立格式的面板开启“锁定联动”，再统一其余面板。

双击文字可改字体、字号、粗体、斜体、旋转角度、颜色和对齐等适用参数。固定右栏方便边改边看。刻度标签可作用于整条轴；轴标题与刻度文字分别编辑。

“移动子图”用于容器移动；编辑轴、点或图例时返回要素编辑状态。联动锁和布局 / 移动锁用途不同，锁定画布不等于锁定格式同步。

5. 同步旋转三维组图

目标：比较两张三维图时，让相机一起变化。

  1. 先接入明确的原生三维场景；分层地图按“先平面、再 3D”流程确认范围与外观。
  2. 进入完整组图视图，打开 3D 编辑侧栏。
  3. 勾选“同步旋转本组未锁定子图”，拖动旋转；滚轮缩放，Shift + 拖动平移。
  4. 确认后应用。需要统一起始视角时用“恢复三维视图”，整次应用可撤销。

默认只改当前子图，同步需要明确选择。兼容、未锁定的原生三维面板参加同步，各自的字体、颜色、色标、比例、缩放和平移保留。多轴或未知几何不自动猜测关联。

PNG、截图和平面 SVG 没有可旋转的原生相机；先按源码 / 数据适配。参见 3D 接入和合成三维例子，无需演示航次的原始数据。

6. 复用设置与绘图语言

目标：这次调好的样式，用于下一批相同结构的图。

  1. 点击画布上方“复制设置给 Codex”。
  2. 选择 R、Python、MATLAB 或 C，复制提示词与 JSON，或下载 JSON。
  3. 回到对话，附上目标脚本与数据，说明复用到哪些变量 / 分组。
  4. 检查轴范围、分组颜色与特殊对象；结构不同的图按语义匹配，不盲套对象 ID。

7. 保存与导出

目标：得到可投稿的图片，也能以后继续改。

  1. 等待“已自动保存”，点击“导出…”。
  2. 选择 SVG / PDF 等矢量格式，或 PNG / TIFF，设置物理尺寸与 DPI。
  3. 默认透明导出，工作台使用白色预览便于观察；需要白底时明确设置。
  4. 选择“图片与绘图代码 / 仅图片 / 仅绘图代码”，以及目标代码语言。
  5. 完整备份时导出项目包；下次用同一项目路径打开，沿用上次设置。

矢量格式不会让已有位图自动变成矢量。项目、来源快照、设置和复现脚本各有用途；不要只保存编辑器 HTML 或临时浏览器地址。

从什么图开始

  • 新图：说明图型、数据、变量与语言；未指定时优先 R，从源码保留语义。
  • 已有源码：保留原分析。Python 原生导入；R / ggplot 同时导出 scene 与 SVG。
  • 仅有 SVG：先编辑外观，数值坐标 / 统计联动需要补充语义。
  • 仅有 PNG / JPG：先参考重绘，再编辑结果；不从像素虚构观测。

多张复杂组图采用逐张完成：编辑当前组的子图，确认联动后排版，完成本组再进入下一组，也能减少同时渲染。

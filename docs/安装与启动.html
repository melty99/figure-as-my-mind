安装与启动

返回 README · 图文教程

环境准备

  • Python 3.10+，建议使用已验证的 Python 3.10 环境或兼容版本。终端运行 python --version；Windows 也可试 py -3 --version。
  • 已安装 Edge / Chrome，或安装 Playwright Chromium，用于预览测试和 PNG / PDF / TIFF 导出。SVG 导出不依赖浏览器渲染器。
  • 首次安装依赖需要网络和足够磁盘空间。运行中的图件项目放在可写路径，避免系统保护目录。
  • 需要 R 源图时安装 R；本包 R 示例还需要 svglite。MATLAB、C 编译器及所选绘图库按用户的原脚本配置。

全新安装

以下 start.py / install_skill.py 命令在完整发行包根目录运行；已安装 skill 内没有这两个入口，可使用 scripts/launcher.py 和 scripts/setup.py。

解压 ZIP，进入含 README.md 和 start.py 的目录。

python start.py --setup

此命令将依赖安装到 skills/figure-as-my-mind/.runtime，不改系统全局包。依赖包括 Matplotlib、NumPy、SciPy、Pillow、Playwright、PyMuPDF、pyproj。发行包不包含它们，不能直接离线首次安装。

python start.py --check

该命令检查依赖并打印绘图服务将使用的路径；不会新建图件。若缺浏览器，运行：

python -c "import sys; sys.path.insert(0,'skills/figure-as-my-mind/scripts'); import bootstrap; from playwright.__main__ import main; sys.argv=['playwright','install','chromium']; main()"

Windows 双击 启动图随我意.cmd；其他系统或终端用户运行：

python start.py

首次启动建立空项目 projects/my-figures，不会创建一大堆模板。界面打开后，自己选一种模板，或接入源码。

安装为 skill

python install_skill.py

默认安装到当前用户的 .agents/skills/figure-as-my-mind。安装时保留包内已配置的本地运行环境引用；不要安装后立即移动或删除原解压目录。需要独立安装环境，可对已安装目录的 scripts/setup.py 再安装依赖。

需要安装到明确目录：

python install_skill.py --target "E:/my-skills/figure-as-my-mind"

自定义目录是否被你的 Codex 配置加载，需要由该配置决定；默认用户目录是本包推荐入口。重新打开会话后输入 $figure-as-my-mind。如果未识别，将解压目录的 skills/figure-as-my-mind/SKILL.md 路径交给 Codex 检查。

更新已有版本

  1. 在旧工作台等到“已自动保存”；必要时“代码与复用 → 打包整个项目…”备份。
  2. 将新包解压到新目录，保留旧目录和 projects。不要把发布包覆盖到个人项目根目录。
  3. 先为新目录安装依赖。运行新 start.py --project "旧项目完整路径"。若旧服务还在运行，启动器可能复用旧服务；需要加载新后台代码时，由 Codex 核实项目身份后停止旧进程，再用新启动器重开。
  4. 若要更新已安装的 skill，先把 .agents/skills/figure-as-my-mind 移到 skills 目录外的备份位置，再运行新包的 install_skill.py。安装器遇到已存在目标会明确拒绝覆盖。
  5. 新会话确认版本 v1.0。旧图件的 project.fam.json、settings.json、sources、figures 和导出目录应继续保留。

打开不同项目

python start.py --project "E:/research/figure-studio"
python start.py --project "E:/research/figure-studio" --no-open

第一条打开浏览器，第二条只启动 / 复用并打印链接。项目不存在时创建空项目；存在时沿用保存设置。地址记录在该项目 .session.json，不要把其中 token 放入公开教程或截图。

自动恢复连接

普通启动后，本项目会由轻量后台守护检测连接。连续三次健康检查失败时自动打开 CMD 尝试恢复，成功后重新打开可用工作台。浏览器显示错误页时也可恢复；不监控其他网站。失败重试间隔逐步延长，避免反复弹窗。

希望电脑重启、登录 Windows 后也自动恢复这个项目，可运行一次：

python start.py --project "E:/research/figure-studio" --resume-on-login --no-open

只为当前 Windows 用户登记这个项目的一个登录快捷方式。不要随后移动 / 删除这份程序目录；移动后重新设置。查看状态、关闭自动恢复：

python start.py --project "E:/research/figure-studio" --recovery-status
python start.py --project "E:/research/figure-studio" --disable-recovery

关闭恢复不会停止已运行的工作台。需要主动停止服务时先关闭恢复。普通启动会重新启用守护；一次性测试用 --no-recovery。已安装 skill 把 python start.py 换成 python <skill>/scripts/launcher.py。本开发目录的唯一 .cmd 支持 -ResumeOnLogin、-RecoveryStatus、-DisableRecovery。

守护仅使用 Python 标准库，不载入绘图数据、不新增服务端口；少量配置与限额日志保存在绘图项目中。恢复沿用保存的设置和原始输入；尚未应用的浏览器草稿需手动保留。原端口被其他程序占用时使用新地址，不终止其他应用。

R 的路径与字体

将 Rscript 加入 PATH，或在本次终端设置路径：

$env:FAM_RSCRIPT = "C:/Program Files/R/R-4.5.3/bin/Rscript.exe"

路径示例需替换成你实际安装的位置。打开 R 后运行 install.packages("svglite")，体验本包 R 示例；原生语义工作流可能另需 ggplot2、jsonlite 等原脚本声明的包。

Times New Roman、Arial 等字体取决于本机是否安装。字体文件不随包分发。投稿前应核对导出文件的实际字形、中文显示及字体替换。

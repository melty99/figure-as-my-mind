# 故障排查

[README](../README.md) · [教程](教程.md)

| 现象 | 处理方法 |
| --- | --- |
| 双击没有打开 / 窗口报错 | 解压全部文件。用终端运行 `python start.py --check` 查看缺少的环境；不要只拷贝 cmd 或 HTML。 |
| python 找不到 | 安装 Python 3.10+ 并在新终端检查 `python --version`；Windows 可用 `py -3 start.py`。 |
| 缺模块 / 依赖安装中断 | 在解压根目录重新运行 `python start.py --setup`，保留完整错误输出交给 Codex。 |
| 无法访问此站点 | 普通启动后由守护连续检查，掉线会自动打开 CMD 恢复并重新打开工作台；等待十余秒及启动时间。若仍失败，查看项目 recovery.log，或运行 `python start.py --no-open`。希望重启后也恢复，按安装说明启用 --resume-on-login。 |
| 端口已被占用 | 启动器会尽量换空闲端口并给出新地址，不会停止其他应用。已有项目端口正在监听但健康检查失败时，不强行重复启动；把项目路径和 studio.log 交给 Codex。 |
| 新包启动后仍像旧界面 | 确认新包路径。旧后台可能仍在运行；交给 Codex 根据项目路径核实进程再重启，不要结束所有 Python 进程。 |
| 只有画布能拖动，内部元素点不到 | 点“完成移动”退出子图移动模式。可启用“锁定画布布局”，再选文字 / 图形 / 图例层。 |
| 右侧找不到设置 | 先选正确编辑层，再点对象或用设置搜索。不同图型与不同接入方式的专用控件不同。 |
| R 图是路径字形而不是文字 | 用 svglite 重新导出；也可在自由装饰编辑中明确替换为可编辑文字。普通 SVG 不会自动推断统计样本。 |
| SVG 无拟合 / 真实 3D 控件 | 需要接入原生数据和对应适配器。不能从路径和二维投影反推真实观测 / 相机。 |
| 改颜色后部分点没变 | 检查“仅当前点 / 同系列 / 本轴 / 当前子图”应用范围、独立覆盖、锁定状态及是否用了连续色带。 |
| 柱子不能上下拖 | 柱高对应数值，界面保护数值轴方向。只允许分类方向调间距。需要新数据时明确导入新表并重绘。 |
| 字体不正确 / 中文方框 | 在本机安装字体，选已安装字体后重导出；同名英文字体不保证含中文字形。 |
| PNG / PDF 报浏览器缺失 | 按安装说明安装 Playwright Chromium，或使用已安装 Edge / Chrome。 |
| 图片有白底 | 预览白色方便观察；导出中勾选透明。查看软件可能用白底显示透明图，可再检查 PNG alpha 或 SVG。 |
| 数据被改写 / 缺失提示 | 不要重建哈希来“修复”。恢复原文件，或将更换后的数据作为新输入重新导入；保护会拒绝覆盖原始捕获。 |
| 另一个窗口修改项目 | 先保存该窗口可复制的设置，关闭重复编辑窗口，重新载入最新项目；不要直接覆盖版本号。 |
| 大组图首次加载慢 | 首次需要布局和绘制；后续缓存更快。先拆分为较小组图；不要为提速删除数据或降低最终导出质量。 |
| 关闭标签后进程仍在 | 本地服务按设计继续运行，下一次启动复用。若需停止，先用 --disable-recovery 关闭自动恢复，再向 Codex 提供项目路径，核实该项目服务后停止。 |

求助时提供：版本号、操作步骤、图型、原生还是 SVG 接入、截图，以及当前项目 `studio.log` 的相关报错。公开分享前遮去个人路径、原始数据和 `.session.json` 的会话 token。

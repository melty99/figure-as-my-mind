## 去重与单图规则

| 旧目录标识 | 新目录处理 |
|---|---|
| `paper-forest` | 森林图 |
| `paper-performance` | 分组柱状图 |
| `paper-boxpoints` | 箱线图 |
| `paper-heatmap` | 热图 |
| `paper-spider` | 折线图 |
| `paper-embedding` | 散点图 |
| `paper-climate` | 折线图 |
| `paper-materials` | 移出模板选择页，旧代码仍保留 |
| `paper-ecology` | 散点图 |

曼哈顿图仅保留一个指标的主图；VK 仅保留元素比散点；分类矩阵去除顶部分组条和计数柱。UpSet 的交集柱、成员矩阵、集合大小是该图的三个不可分离组件；KM 的风险表、热图的色标/类别注释保留。新目录不提供不同图型拼接或多场景比较组版；用户仍可自行选择任意单图组成组图。

当前目录森林图使用已核对的论文汇总值，其余为示意输入。旧论文参考保留在 [paper-templates.md](paper-templates.md)。新增 13 图型由显式数组计算，不能作为真实科研结果。弦图用对称非负关系矩阵；网络图保留节点和边表；UpSet 按逐记录布尔成员关系计算互斥交集，不混用包容性交集；桑基图两端使用同一流量；韦恩图圆面积不表示计数；雷达图输入共用 0–1 标度；三元图每行成分和为 1。核密度采用 Scott 带宽，山脊图明确为等峰高展示。一致性图使用样本差值标准差的 ±1.96 倍，不把参考界限当作界限估计的置信区间。

## 实际坐标框尺寸

组图的主坐标框宽（英寸）= 组图宽 × 子图容器宽比例 × 坐标框宽比例，高度同理。默认以第一张可联动子图为基准，将实际宽高反算到跟随子图；容器尺寸各自独立。修改其他子图的绘图区尺寸时自动进入独立模式，可再选择跟随。独立与锁定布局不接受自动更新。若目标尺寸超出较小容器，明确拒绝，用户可放大容器或关闭联动。具体模式、毫米尺寸和横纵间距见 [composition.md](composition.md)。

坐标框层提供八个手柄，边手柄改变一个尺寸、角手柄改变两个尺寸，对边固定。拖动虚线本身只移动坐标框。移动坐标框不触发其他框位移。源数据、误差和刻度通过相同原生坐标变换重绘。联动属于一次编辑，可撤销/重做，保存后重新打开一致。

默认联动普通二维直角坐标框。固定比例（含极坐标）、三维、无轴示意图、多个主坐标框和锁定框保留布局；因此并非任意异构图都强制变为相同长方形。色标不算主坐标框。用户可在坐标框层关闭“组图坐标框尺寸联动”，或用组图的统一绘图区操作重新启用。

## 版本与复现

新建目录模板由 `templates.build(kind, edition='single-v3')` 生成；实现位于 `scientific_templates.py` 及类型模块。旧脚本不传该 edition 时仍调用原 builder，`single-v2`、`paper-v1` 和 `legacy` 的布局与输入不变。已保存的模板实例是用户图件，不会因目录去重而被删除、替换或改名。专门统计图接真实输入时应修改源代码中的对应结构，不自动套用通用 X/Y 映射。

新增 12 图型的输入和方法边界见 [publication-tools.md](publication-tools.md)。

新增 `dotplot` 堆叠点图、`dumbbell` 哑铃图、`mosaic` 马赛克图、`parallel-coordinates` 平行坐标图；以上合计 73 种去重单图。前两种按观测绘制，马赛克以明确计数绘制面积，平行坐标以明确多变量表绘制。同一类型的圆形树、半小提琴等作为画法选项，不新增重复卡片。

当前目录另包含 `scatter-matrix` 散点矩阵、`windrose` 风玫瑰、`trajectories` 轨迹图、`transition` 转移图、`section` 剖面图，共 78 种。实际选择项以 `templates.CATALOG` 为准。

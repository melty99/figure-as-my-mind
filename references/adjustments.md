# 常用调整与复用边界

工作台的面板在预览后读取当前原生对象。坐标范围、图例与相机读取有效设置。原始 `.figure` 和 `sources/` 保留；改变样式不改变原数据。只有明确的 Newick 输入会重建树拓扑。

| 位置 | 可调整内容 |
| --- | --- |
| 全图 | 字体族、字号层级、粗细/斜体、文字色、背景/透明、物理尺寸、线宽、网格与边框 |
| 色标 | 连续色带、范围、线性/对数/中心归一化、轴名及字号、刻度位置/字号/小数位、轮廓线、显隐 |
| 坐标 | XYZ 名称及范围、反向、尺度、刻度位置与自定义文字、旋转、数值格式、百分比基准、间距、次刻度、网格线型、各边框显隐 |
| 系列 | 单系列颜色、透明度、线宽/线型、叠放顺序、点形与大小、点填充/边线；气泡的面积倍数保留原始相对面积 |
| 图例 | 显隐、位置、轴内/轴外锚点、列数、标题与字体、背景与边框、透明度、点倍数、行列距和线段长 |
| 对象 | 文本、字体、对齐、填充、边线、虚线、透明度、移动、旋转中心、角度、缩放、隐藏和几何 JSON；添加文字、箭头、矩形、圆 |
| 组图 | 自动排列、列数和间距记忆、顺序、独立子图设置、相对位置/尺寸、标签格式和偏移、透明背景、原生图物理字号和线宽保持 |
| 导出 | SVG/PDF/PNG/TIFF、72–1200 DPI、毫米尺寸换算、透明背景、同名文件区分 |

85×65 mm 和 180×130 mm 是便捷尺寸预设，不能当作某个期刊的投稿要求。期刊要求由用户提供或另行核实。

native.axes 的 x/y/z 前缀字段如 `xtickFormat='fixed'`、`xtickDecimals=2`、`xtickRotation=30`、`xlabelPad=10`；`percent` 默认以 1 表示 100%，用户数据以 100 表示 100% 时设置 `xpercentBase=100`。自定义刻度文字必须提供等长的刻度位置；多语言文字需要本机对应字体。

### 主刻度设置（Major ticks）

右键坐标轴打开范围侧栏，或在“刻度与网格”选择轴，可设主刻度间隔、主刻度数量（含两端）或自定义数值位置。0–10 范围内，间隔 5 / 数量 3 显示 0、5、10；间隔 2 / 数量 6 显示 0、2、4、6、8、10。主刻度数量比区间数多 1。按间隔从 0 的整数倍选取范围内位置，数量模式在当前坐标变换中等距；对数轴按对数等距，不按原数值线性等距。

`native.axes[axis].xmajorTicks`（或 y / z 前缀）示例：`{'mode':'interval','interval':2}`、`{'mode':'count','count':6}`、`{'mode':'manual','values':[0,5,10]}`。`{'mode':'auto'}` 恢复捕获原图的定位器，优先于旧 `xticks` / `xtickLabels` 覆盖。新策略不会改变轴范围或原数据；随范围重新计算，网格跟随主刻度。数量和手动位置上限 200，过密间隔拒绝保存。分类 / 日期轴保留原标签与日期语义，专门间隔在源语言中设置。数值格式、字体、旋转和次刻度独立。分层地图平面确认后三维保留此策略，组图仅改当前子图；复制设置与复现包包含该设置。

`native.artists[语义GID]` 保存 color/lineWidth/lineStyle/alpha/zorder/marker/markerSize/sizeScale 等。误差线杆属于 LineCollection，端帽属于 Line2D，在系列列表分别选择。连续色带只作用于含标量数组的图层，分类散点不会被连续色带覆盖。对数颜色范围要求正值，中心归一化的中心必须处于范围内。

`native.legends[轴索引]` 保存 loc/anchor/ncols/fontSize/title/titleSize/frame/alpha/faceColor/edgeColor/markerScale/labelSpacing/columnSpacing/handleLength。图例系列颜色随原生系列修改更新；特殊手工图例找不到原系列时保留它原来的句柄。

一键“应用到勾选图件”和内置批量对话框的“应用当前图的全图格式”应用 style 字段。若还要复制图例、刻度、色标或系列参数，由 Codex 读取复制的完整 JSON，按目标图语义匹配 native 字段；不同单位/变量的数据范围、模型和坐标名称不能隐式复制。

图外图例或很大的字号可能超出画布；调整坐标框 `position=[左,下,宽,高]`、画布尺寸与图例锚点，并检查导出。PNG/TIFF 透明导出保留绘图数据和已有图层；通用 SVG 内自行绘制的背景对象、位图中嵌入的背景仍需在对象面板或源码中处理。

新组图默认 `physicalFonts=true`：Matplotlib 重绘尺寸为面板 w×组图宽、h×组图高，点大小、文字字号和线宽不随面板缩放。物理尺寸由组图与面板控制。若原图很复杂，可加大面板或减少字号，检查图外元素。关闭该选项恢复整张 SVG 的等比例缩放；已有项目缺少此字段时采用原方式，保留其外观。

运行回归：`python scripts/test_engine.py`；`python scripts/multiround_qa.py --round 1 --root <独立测试目录>`，随后按 2–5 运行。测试用独立项目，产生实际浏览器截图、每轮 JSON 和导出文件，失败记录与重测记录均保留。不要对用户的绘图项目直接执行这些测试。

# 科研工作流检查与回归

用于用户要求全面 debug、优化或多轮检查时。优先复现当前具体问题，在隔离项目使用真实浏览器操作；保存每轮检查证据、失败原因及修复后的复测结果。不要将重复执行同一检查计作新的覆盖轮次。

用户要求检查真实接入流程时，先建立可追溯的输入表，用独立 Python/R 脚本实际作图，再导入。覆盖数据与模型核对、名称与图型识别、文字编辑、框变化、从属关系、颜色与图例、专用画法、真实鼠标、组图、变量选择、复现与导出。模板检查不能替代此流程；没有点实体的图型仍需检查其真实矩阵、路径或面对象。断言不能用空列表的 all() 假装拟合成功。坐标位移比较应先统一 DPI、坐标系与预览缩放。保留成功图型的检查点，续作时只重试失败或受修复影响的部分。

拓展变量时核对误差与目标量的单位及来源，不将旧 response 的标准误套给 feature_1 等不同观测量。示例图的合成数据声明应保留在输入、来源和说明中，不伪称论文或患者输入。

## 十轮覆盖

| 轮次 | 科研使用场景 | 核对要点 |
|---|---|---|
| 1 | 选择观测与相关分析 | 分组 / 合并、未命名观测、缺失配对计数、有效样本、相关与回归分开 |
| 2 | 公式与统计文字 | 真实系数、有效数字、独立字体颜色、全局格式与对象覆盖优先级 |
| 3 | 多选与拖动 | 相同屏幕位移、不同缩放和坐标变换、从属对象不重复移动 |
| 4 | 组图、复位与锁定 | 子图与来源隔离、复位后编辑读到有效默认值、必要跟随仍生效 |
| 5 | 统计结果复现 | 固定种子、保存重开、脚本重放、PNG / PDF / SVG 一致 |
| 6 | 柱图和误差 | 单柱宽度、堆积画法、误差位置联动而颜色独立、仅模型显示无残留 |
| 7 | 箱线细节 | 中位数、均值、须线、端帽和样本点独立编辑，跨层切换保留所选箱 |
| 8 | 分布与历史 | 箱范围、点筛选、均值画法、原始图恢复、最多 10 次撤销及重做分支 |
| 9 | 多类型和边界 | 热图按实际矩阵尺寸核对标签，VK 按实际区域 / 边际图组成提供选项；PCA、树、曲面等保留语义 |
| 10 | 成组交付 | 不等尺寸面板、统一格式后独立精修、真实高分辨率导出和源文件保护 |

另测中英文混排、窄屏、批量失败原子性、过期修订冲突及实际重绘耗时。只改外观应命中数值缓存；单独报告计算耗时与完整重绘耗时，不将缓存命中时间当作全部界面响应时间。

## 已建立的回归约束

- 已命名数据旁的未命名散点、带标记折线仍是可选观测。未知匿名连续模型线不按外观伪装成独立样本。
- 原生字体、颜色、粗细先在 Matplotlib 中按全局→图层→独立对象解析，SVG 不再次用全局 CSS 覆盖。SVG 对象的显式覆盖继续最后应用；外部 SVG 仍支持全局格式。
- 中英文文字保留用户选择的英文首选字体；包含中文时追加已安装的中文字体作字形回退，避免测量和导出缺字。不捆绑或联网下载字体。
- 组图 `fitLabels.reset` 必须在前后端都阻断来源覆盖，否则复位后的第一次拖动会跳回来源坐标。
- “仅显示拟合”隐藏所选观测及其误差杆/端帽；切换回观测画法后恢复，未选系列保持原样。
- 修改箱体与修改中位数等属于不同层，快捷入口保持选中对象，切换不占撤销次数。
- 密集观测的手柄中，当前选择最后绘制以优先命中；从列表选择第 500 个以后的观测也应有手柄。测试应核对实际移动的是选中 ID，不能只看画面变化。
- 自动保存或无关重绘后，同一图、子图和编辑层保留输入焦点、未提交草稿、光标位置及面板滚动；切换图件或层时清空设置搜索，避免旧搜索隐藏新控件。范围选择不占用绘图撤销次数。
- “搜索当前层设置”仅按当前控件名称筛选，展开命中项所在折叠区，不按当前数据值过滤；无匹配时给出反馈。纯界面搜索和选择提示不得写入科学数据。

## 更新既有工作台

更新前读取最新项目及会话，不复用上一轮的旧修订号。备份安装代码和当前设置，计算源码、输入、捕获图及导出哈希。测试通过后同步技能和项目复现运行时，验证进程确属该项目再隐藏重启，保留原端口与会话。安装后只读预览，不把测试样式写入用户项目；核对全部原文件哈希及所有已有图件渲染。任何测试脚本遇到异步按钮，等待该动作真正结束再断言，不能将旧模板固定尺寸或旧图层位置当作当前界面契约。

现场只读检查应在浏览器阻止 `/api/save` 请求并记录请求方法。导出、样式复用与比较面板的打开包装函数可能先 flush 保存；这类操作放在隔离项目。用户并行保存时，文件字节变化不能直接当作检查窗口的修改，结合实际请求记录判断，保留用户新状态。

## 57 图型巡检的约束

- 多字体列表清除分隔符两侧空白及引号，独立文字、图层文字和图例条目采用同样的解析；已选择的英文字体继续优先。
- 地图比例尺和声明独立的参照线不接受通用折线画法转换；混淆矩阵使用其计数 / 比例文字控件，旧通用单元格标签设置不能叠加第二套文字。
- 专门统计图不以其内部折线、矩形或柱形自动推断通用画法。隐藏轴的示意图与三维图不展示不会生效的二维附加轴选项。外部未标记的原生图保留通用控件。
- 缩放和宽度手柄按 screen CTM 计算尺寸，预览缩放不改变可点击大小；测试使用实际 DOM 几何，区分 SVG 描边扩展与手柄填充边界。坐标框模式下内部可直接拖动，长按对象后拖动或按 Shift 框选仍可选择跨层内容。
- 保存只预渲染实际改变原生设置的单图或面板，按面板身份匹配旧状态，不因选中其他图而重复渲染所有组图。来源原生设置改变及新面板仍需要验证；无效设置仍在写入前拒绝。
- 组图性能分别测量首次绘制、重复预览、切换子图和真实位移到保存完成。拖动测试避免被吸附回原处，并验证确实改变位置；单独运行计时，勿与全量测试争用 CPU。超过旧缓存容量的组图必须重复打开，确认未改的子图无需重新绘制。复用 DOM 后仍检查取消临时编辑、整体撤销、内容变化失效、来源隔离，以及导出位置与界面一致。

- 三维轴的普通 aspect 可能报告 auto，但绘图区仍由 box aspect 保持正方形；侧向手柄也需同步调整宽高，保持相机与空间轴比例，不以没有报错替代实际尺寸变化检查。

- 极坐标观测的展示位移应通过 transData ↔ transAxes 的完整变换解释，再回算 θ / r，并选择最近的角度分支；不能把水平 / 垂直拖动直接加到角度和半径上。绑定注释同移，改变物理绘图区大小后解析坐标保持。
- 独立 ScalarMappable（地图区域和速度箭头）的原始数值、色带及色标必须共同编辑。自建 Figure 捕获的弱回调可能不随序列化恢复，需要显式更新色标并保留其对象 ID；色标挂接真实主轴，框移动时按相对关系跟随。

- 普通二维绘图区用实际毫米尺寸核对，固定比例、极坐标和三维遵守原比例约束。画布毫米 / 英寸切换只转换显示，不改变物理尺寸或占用绘图撤销次数；无效或空白数值提交后，输入框恢复最后有效值。
- SVG 对象列表按文字、类型与 ID 搜索，过滤上限不能阻止定位第 700 项以后的对象；过滤和自动保存保持当前选择。多行文字必须在实际 SVG 中逐行显示，保存、重开、字号、旋转、缩放和重接入均保留换行，不能只检查 textarea 值。
- 仅导出代码时不启动图片规格查询，也不显示 DPI / 像素警告；切回图片导出仍核对实际尺寸。异步规格查询不能把旧图片模式的结果写入当前代码模式。

## 全目录用户数据实测的补充约束

缺失协变量出现在 sourceRow 时，元数据仍须是标准 JSON，缺失以 null 表示；不得为了浏览器可读而写回来源或补零。R/SVG 未标记文字要检查默认数据层下的实际单击 / 拖动，也检查框选后的包围区域移动；Alt 精确拖动跳过吸附。大型项目的压缩撤销历史须实际重开后撤销 / 重做，保留完整十步而不减少次数。R 风玫瑰四方位标注须目视核对，图例不能遮挡东向文字；双向转移计数从原输入读取并分别检查坐标，不能用固定示例数代替当前 CSV。

## 关联文字与无效位移

- 已知观测关联的饼图类别 / 百分比、绑定注释等必须保留独立文字选择；只有语义记录实际缺失时跳过，不能把存在实体 ID 当成不可编辑文字。字体、颜色、隐藏和独立位移只写展示覆盖。实体和关联文字同时选中时，提交与实时预览均去重；只移动实体时标签仍跟随。
- 柱 / 箱沿受保护数值方向的纯位移不写入零分类偏移，不迁移旧位置覆盖，不占撤销次数；横向对象检查对调后的数值方向。多个系列分类调距保持组中心，且每个轴只计算一次。
- 图库搜索同时检查单图和组图，无结果提示须按两者合计判断；中英文图型、常用别名及首尾空白均在真实界面检查。

## 输入能力与重建对象

- 森林自动数值列只在显式且有限、区间有序、行数匹配的原始行表存在时提供；原画法不要求额外行表。生成文字与列标题不能被再次计作原行，修改有效数字后控制仍可用。数值字符串在展示副本中转换，不写回输入。
- 等值线数值场不能反推观测；核密度入口只在声明有限、非共线的 XY 样本时提供。核密度更新保留已有绘图区与色标几何，已有观测对象身份保留，新显示样本有稳定 ID，可编辑展示；不能再次挤压主轴或留下不可选择的新点。

## 切换对象、节点编辑与轴外文字

- 在点、误差、图例、标题和自由对象之间切换后，格式复用读取当前对象和当前层；误差不能借用数据主体颜色，自由文字不能沿用上一次观测 ID。
- 切换图件、面板、对象或不适用的层时结束路径节点模式；拖动节点将键盘焦点交给画布，使 Ctrl+Z 撤销图形操作。数字输入中的普通文字编辑仍保留其输入行为。
- 节点模式显示控制点，普通装饰变形手柄暂时隐藏。只缓存当前路径解析；一帧复用同一 CTM，批量挂载手柄。滚动/尺寸变化以 requestAnimationFrame 合并更新，不能限制实际可编辑的节点数量。
- 论文版式的“按文字适配留白”检查明确的轴外类别文字与轴名称重叠，按实际文字边界向外避让并留空。原始数值、文字内容和统计含义保持；极坐标、三维和未知 SVG 不推断这种二维轴关系。版式修改为一个可撤销操作。
- 来源发现遍历所有来源目录并登记新文件；已登记文件仍执行原数据校验，不用目录扫描优化省略内容/路径保护。

- 检查缓慢、小幅拖动并在第一步停顿超过长按时间：已经发生的单对象拖动不能被框选计时器抢占；真正静止长按仍进入框选。分别验证原生标题和未标记的 R / SVG 文字。
- 旋转面板字母后移动组图，核对文字与容器在预览、提交、键盘微调和重开中的屏幕位移相同；旋转中心必须随文字锚点更新。移动标签不遮挡科学图内的标题或字母。

## 2026-10-18 回归约束

- 启动在 DOMContentLoaded 后执行，确保组图布局和逐张工作流脚本已装载。用快速本地 API 与延迟 composition.js / composition_workflow.js 的组合复测，不靠重复刷新绕过偶发空白。
- 保存成功与实际画面更新分别等待：保存完成后还须核对当前图件、子图、视图模式及最新视觉签名，再断言 SVG 的颜色或字体。旧单子图不能作完整组图的视觉证据。
- 坐标框层中，主图八向手柄在相邻色标控件之后挂载，避免三元图等紧邻色标的图型缩放时误选色标；切至图例层仍完整提供色标八向调整。
- Ctrl+S / Command+S 与顶部保存使用同一入口；右侧对象草稿应用后保存，错误保留草稿并提示，保存失败不得产生未处理 Promise。右侧草稿打开时导航保持不可操作，顶部保存按钮可用。
- 联动锁定等非视觉刷新仅在图件、子图、已绘 SVG 与视觉签名全部一致时保留对象元数据。验证锁定后仍可直接修改和缩放，切换图件、真实图形修改及撤销不能沿用旧元数据。
- 原生 R 包与项目运行时都保留 bridge.R、bridge_semantic.R、ggplot_bridge.R；运行时另外包含 ggplot_import.py。需要实际执行导出的 R 包和独立运行时导入，不只检查 ZIP 文件名。

已完成组图再次编辑时，afterChange 清除完成标记的纯 UI 保存不能覆盖科学修改的待重绘标志。验证时等待 savedEpoch===editEpoch 以及 renderedKey===viewKey(current())，同时实际核对文字 / 外观；网络故障下保留草稿与最后有效画面，不用强制刷新伪装成功。


SVG 连续色带检查合法的局部端点（如 20% / 80%）和同位置的突变节点；节点颜色编辑、实时预览、透明度、撤销和导出均应保留原位置与顺序。SVG 的合法渐变规则与原生数值色带的严格节点约束分别验证。

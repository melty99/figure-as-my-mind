# 三维与立体显示

顶部“3D”打开固定右栏的草稿编辑器；也可展开数据层中的“三维与立体显示”，或在双击编辑器中选择同名分类。桌面图件库和绘图区保持原有位置、尺寸。输入实时预览，取消不保存，一次应用一次撤销；组图仅修改选定子图。

| 输入 / 图型 | 可用画法 | Z 的含义 |
| --- | --- | --- |
| 已捕获 XYZ、曲面、3D 线 / 点等 | 原生三维相机 | 原始第三维数据 |
| 柱、饼 / 环形、折线、点 / 气泡、箱线、小提琴、直方等可识别直角几何 | 二维原图 / 立体显示 | 明示的展示厚度，不是新增观测 |
| imshow、直角 pcolormesh 矩阵 | 二维 / 三维曲面 / 三维柱格 | 捕获的矩阵原数值 |
| 带 levels 与 allsegs 的等值线 | 二维 / 三维等值线 | 已知的等值，不推断完整网格 |

每个坐标区域分别保存模式和相机；可设置 X/Y/Z 空间旋转角（各 0–360°）、透视 / 正交、XYZ 比例、视图缩放、背景面和网格，立体显示还可设置厚度与明暗。饼图默认不显示辅助坐标框，保留环形孔洞和原扇区角度。热图行列、数值色带、负值、缺失掩码保持；曲面颜色按真实有效顶点的面片值映射，不补造高度。厚度不会被自动归一化抵消。

实现：`scripts/spatial.py` 在原图样式、统计、误差和关系处理之后，从当前捕获几何生成临时三维轴；保留原数据对象、ID、系列、复杂图例及关联。原始来源、`.figure` 和数据文件不写回。三维散点深度排序仍对应原观测身份。切回二维重新从原捕获和当前设置绘制，不丢失二维编辑。预览与矢量导出共用路径，多语言代码包保留原分析源码。

`native.spatial[轴索引]` 保存 `mode`（original / solid / surface / columns / contours）、`depth`（坐标跨度比例）、`shade`、`camera`、`zoom`、`panes` 和 `grid`。相机允许 rotation=[X,Y,Z] / projection / aspect；rotation 为固定空间轴依次 X→Y→Z 的旋转，优先于兼容字段 azimuth / elevation / roll；旧 `native.camera` 继续兼容，分轴设置优先。厚度 / 模式尊重数据层锁定，相机尊重坐标框层锁定；已有对象锁定时不允许整轴改变其展示模式。立体展示中的二维观测不开放不明确的屏幕拖动，外观、宽度和相机仍可编辑。

普通 SVG / 位图、极坐标、二维对数尺度、非直角矩阵网格、多图像混合或带箭头的复合注释不自动猜三维结构，需原代码提供对应适配。矩阵三维最多10000单元；超限明确拒绝，不悄悄抽样或丢数据。平面显示不能变成真实三维测量。模板目录仍按单一图型组织；立体画法属于当前图的选项，不复制相近模板。


## 鼠标交互与倾斜 / 压缩

顶部 3D 打开右栏后，已经显示为三维的原生几何可直接操作：左键连续旋转 360°，Alt＋拖动沿视线旋转，Shift＋拖动 / 右键拖动平移，滚轮缩放，双击恢复原视角、缩放和位置。角度、缩放有滑块与数字输入。选“倾斜 / 压缩”后，左右拖动调整 c，上下拖动调整 d；a / b / c / d 与精确平移可在折叠区分别输入。改变这些投影系数不自动重新适配整体缩放。复制三维设置可交给 Codex 复用。

鼠标帧用捕获的当前三维点、线、面在本地 Canvas 投影，不逐帧请求服务器、不改变原观测。拖动期间坐标标记使用同一投影几何，深度明暗采用轻量预览；松开 / 输入停止后，用原 Matplotlib 内核产生精确 SVG，最终保存和图片 / 代码导出使用此精确结果。不会从 SVG / 位图推测 XYZ；不支持的专用几何明确回退到右侧精确参数，不默默丢弃对象。

`native.spatial[轴].screen=[a,b,c,d]` 作用于中心化的屏幕投影，`pan=[横向,纵向]` 以当前绘图区宽高为单位，Y 为屏幕向下。它们只覆盖展示，相机、缩放、图例和原数据独立；行列式必须大于 0.02，避免折叠。对应轴的数据、误差、坐标轴、刻度、网格、背景面和明确绑定注释共同变换；标题、图例、其他子图保留独立排版。三维轴绘制在数据组以外的网格 / 边框也明确登记并同步。`camera` 保留原轴的垂直方向与透视焦距。

局部视图在关闭时释放；取消不提交，应用一次占一次撤销。组图只改变当前子图的内部视图，即使锁定外部画布仍可调整；坐标框层锁定则禁止直接修改相机、平移与投影。


空间角通过旋转矩阵保存朝向，鼠标绕当前屏幕轴连续旋转，不在正上方或正下方截停。X/Y/Z 数字是同一朝向的固定轴表示，过特殊位置时读数可换成等效角度，画面保持连续；0° 与 360° 同向。旧工程的方位 / 仰角 / 滚转仍可读取，不在打开时重写。

改变原生 XYZ 范围时裁剪线段、误差集合、点和面片，裁剪产生的交点不显示为新测量标记；带数值映射的样式保持原对应关系。数据坐标文字超出视窗时隐藏，标题和图例保留独立排版。明确分层地图还重建当前视窗的边框、角点连接线、层名锚点与默认数值刻度；显式手工刻度保留。扩大视窗不会向原数据范围之外外推场值。

# 透明画布与子图移动（v1.0）

## 交互与缓存

切换编辑子图只更新右侧属性，不替换整张组合图 SVG；重复选择可复用当前内容对应的属性信息。只有 x/y 位置变化时直接更新面板与标签，字体、颜色、尺寸、标题内容和来源设置变化仍重新生成有效预览。取消内部对象的临时编辑可强制刷新，不能因复用旧 DOM 留下未保存的变形。

拖动按浏览器刷新周期合并鼠标事件，释放鼠标时处理最后位置；保持吸附、邻图跟随、锁定及整体撤销。后端分别缓存原生渲染与已处理引用 ID 的子图 SVG，最多各 128 条，并按 64 / 32 MiB 的序列化载荷预算淘汰旧条目（单个超大图可保留）。实际进程内存还包括 Python 对象和绘图库，不能把载荷预算当作总内存上限。缓存仅驻留内存，不产生临时缓存文件；源捕获时间、设置、DPI 或面板顺序变化会失效。首次打开及真正修改内容仍需绘制，性能报告应分别记录冷启动、重复预览、浏览器切换及移动保存耗时。

## 操作

新图的 `style.transparent`、新组图的 `transparent` 默认为 true。透明画布在编辑器里以白底预览，白底属于 HTML，不进入 SVG / PDF / PNG。导出窗口沿用当前值，取消透明时明确传 false；在“画布与组图”层关闭透明可编辑不透明背景色。已有被用户明确设为 false 的项目不会仅因打开而被改写；用户要求统一透明时再在备份后迁移设置。

当前 78 种目录模板不添加左下角说明。既有已识别的 synthetic-demo / published-summary 模板按缓存克隆移除 Figure 左下角文本，捕获文件不改写。原始图中的作者注释、图内统计文字和数据标签保留；演示说明、原论文信息和计算输入继续保留于来源信息。

组图点击“移动子图”，每个面板有完整轮廓；在其内部任意位置按住左键拖动，包括绘图区内部、文字与空白。新组图默认进入图内对象编辑模式。选择坐标框、数据、文字、图例等非画布编辑层时自动退出移动模式，移除整块覆盖。“完成移动”返回图内编辑，整块拖动区域随之移除。移动面板保留 x/y 之外的参数、坐标框实际宽高和观测位置，所有图内文字跟随它。移动条显示在面板框外，避免遮住标题和面板字母。旋转过的 a / b / c 标注在拖动预览、保存、方向键移动与撤销时同步更新自身旋转中心，保持与子图相同的屏幕位移。移动条仍可聚焦，方向键移动 1 预览像素，Shift + 方向键移动 10 像素。

吸附参照附近面板的边缘、中心及当前间距。邻图跟随根据操作前同排 / 同列位置推断；冲突时尝试最近可用空位及原参考面板位置，不更改图的宽高来强行塞入。空间不足拒绝不合理的新位置并保留最近可用位置，不宣称任意布局的全局最优解。关闭跟随后可独立移动并允许用户有意叠放图形。

## 画布布局锁与图内编辑

组图下方“锁定画布布局”只固定组图画布宽高及每张子图的外部容器位置、尺寸和顺序（`group.canvasLayoutLocked`）。锁定后移除移动覆盖并禁用移动与排列，坐标框缩放、轴范围、字体、标题、图例、色标及观测外观仍可编辑；原有坐标框跟随关系保留。此锁与“子图布局模式：锁定布局”不同，后者还保护内部坐标框几何。不要为了固定外部位置把每个子图自动改为layoutMode=locked。

锁定与解锁各占一次可撤销修改并自动保存；重开保持。后端拒绝仍锁定时移动/缩放/重排容器和改变画布大小。直接设置原生轴几何不受该锁影响。选择编辑层时取消未提交的面板拖动预览，避免覆盖留在数据对象上。新图和旧用户设置均不自动迁移坐标或尺寸。

## 尺寸、间距与每张子图的联动选择

画布层和高级全图面板共享“当前子图尺寸与联动”设置：

- **跟随第一张图**（默认）：坐标框实际毫米宽高与第一张可联动图一致。若第一张是固定比例、三维、多主轴或无主坐标框的特殊图，则以首个普通二维主轴为基准。
- **独立调整**：不接收自动尺寸或位置变化，自己仍可拖动、输入位置和尺寸。修改第二张及之后子图的绘图区宽高或拖动其缩放手柄时自动切换为独立；重新选择跟随即可加入联动。
- **锁定布局**：停止尺寸与位置联动，也禁止直接拖动、键盘移动、输入位置 / 容器尺寸 / 坐标框位置。字体、颜色、标题文字仍可编辑。全局画布宽高变化时保持锁定子图物理位置和大小；撤销和重做保持同样语义。遇到冲突不强行挪动锁定或独立子图。

“绘图区宽 / 高（mm）”调整真实坐标框，数据、误差杆与刻度按轴映射重绘；“子图容器宽 / 高（mm）”包含标题、外部留白，可单独调节。容器无需相同大小。容器不足以容纳跟随坐标框时拒绝并提示先增大容器。

“横向 / 纵向间距（mm）”分别影响吸附与避让；点击“应用间距并排列”按当前列数整理跟随面板，保留每张图的宽高及独立 / 锁定位置。原“应用等大排列”为明确调整跟随面板容器的命令，同样保留独立和锁定面板；空间不足或冲突拒绝。所有真实修改进入最多十次撤销历史并自动保存。

## 标题与面板字母

自动整理在副本上以实际点数和字体测量总标题：给面板字母预留横向空间，在顶部留白中居中、按词 / 中文字符换行，需要时适配字号。坐标框尺寸保持。导入图没有总标题时不虚构标题。源图和持久化的原始标题文字保留，自动换行是组图显示设置。

手动拖动总标题或输入其位置会令当前面板 `autoTitle=false`，保留独立调整；其他面板继续自动布局。可在画布层重新开启。全组 `autoPanelTitles=false` 时保留原有总标题与 labelX / labelY。面板字母默认小写 a、b、c，位置与图件绑定；用户移动面板时字母不被偷偷重新编号，必要时修改“子图标注”。

画布层提供“当前面板标注自动布局”及水平 / 垂直 pt 位置；全图面板原有的“标签水平偏移 / 垂直偏移”编辑同一设置。任一手动输入自动切换为该标注独立定位，并保留另一个方向的当前位置。平衡邻图位置的规则也同时用于全图面板的 X / Y 数值输入。数学标题不拆开 LaTeX 定界符；锁定注释层保留原标题，锁定画布层禁止该面板被直接拖动或键盘移动。

## 保存字段

- `group.transparent`：全组背景；true 强制子图背景透明，false 显示组图背景色。
- `group.autoPanelArrange`、`group.snapPanels`：邻图跟随 / 避让与吸附，默认 true。
- `group.autoPanelTitles`、`panel.autoTitle`、`panel.autoLabel`：总标题 / 字母自动布局与面板独立选择，默认 true。
- `ui.panelMoveMode`：移动模式偏好，切换不占绘图撤销次数。
- `panel.x/y`：唯一被面板位移写入的几何参数；容器 w/h、来源引用和图内覆盖保持。
- `panel.layoutMode`：follow / independent / locked，未声明默认 follow。
- `group.layout.gapX/gapY`：相对画布宽 / 高的独立间距；界面按毫米显示，旧项目缺失时各自读取 gap。
- `native.compositionHeader`：组图渲染副本的内部排版参数，不写回来源图。
- `native.hideTemplateFooter`：已识别模板说明的展示选项，默认 true。

group render 和 inspect 使用同一个 panel_record，确保所见标题位置就是拖动起点；预览标题位移时暂时关闭该面板自动排版，最终保存同一选择。`composition.py` 复制到项目 runtime；交互移动条属于 HTML，不进入导出。


## 批量复杂组图：逐张完成

项目有多张组图时，默认进入“逐张编辑组图”。上方显示第几组及完成进度；左侧只列出当前组的子图。选一张后，画布只绘制该子图，右侧修改的也是这张组图内的子图设置，来源单图和其他组保留。

1. 先选择子图精修。默认开启“本组联动修改”，以当前修改的子图为参考，将本次改变的兼容字体、坐标框实际宽高、图例格式和可匹配系列样式应用到本组其他未锁定子图。坐标范围、标签文字、统计方法和原始数据不随格式一起复制；无法匹配的系列明确跳过。
2. 需要保留例外时，在左侧勾选该子图的“锁定联动”。它仍可单独编辑，但不接收也不广播自动联动；解除锁定本身不会重新套用其他子图的旧设置。“锁定联动”与禁止移动的“锁定布局”是两个独立选项。
3. 点击“检查联动 · 调整组图”，才绘制当前整组，调整分布、间距与标注。可随时“返回子图编辑”，保留当前选择和修改。
4. 满意后点击“完成本组，进入下一组”。先保存成功，再标记完成并读取下一组；未应用的对象编辑草稿或保存失败会阻止进入下一组，修改保留。可回到上一组，重新打开项目也会保留进度。

一次联动操作整体撤销或重做，最多保留十次。撤销格式不会把进度跳回别的组图。完成过的组再次修改时会取消其完成标记。“退出逐张编辑 / 图件管理”可返回普通图件库，不自动将当前组标记完成。

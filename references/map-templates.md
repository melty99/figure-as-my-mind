# 地图模板与地理数据接入

v1.0 开发版新增八种单图模板：位置与采样点、分区填色、比例符号、空间栅格、空间等值线、空间矢量场、空间流向和轨迹。它们按图型分类，地图色标与图例是解释组件。预览白色，画布和默认导出背景透明。

## 数据与底图

离线底图为 [Natural Earth 1:110m](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/) 的真实陆地及区域多边形，固定版本 5.1.2；遵循其 [public domain 条款](https://www.naturalearthdata.com/about/terms-of-use/)。`scripts/map_data/manifest.json` 记录源链接、版本、源文件和分发文件的 SHA256。运行和导出不联网下载底图。此小比例尺底图用于区域示意，不能替代航海、测绘、精细边界或站点所在岸线的判定；需要更高分辨率时接入用户提供的适当矢量文件。

真实地理边界之外，站位、数值、分组、场、速度、流量和轨迹均为固定种子示意输入，不是论文测量。`sources/*.template-data.json` 保存经纬度、原数值和显式排列；来源与实现可从“代码与复用”查看。成图不添加左下角说明。分区填色只给初始示例区域定义数值；移动范围到其他地区时无值区域保持灰色，不生成研究结果。

## 地理联动与编辑

数据层或坐标框层“地图投影与图层”提供等距圆柱、Web Mercator、地图西/东/南/北边界、底图、经纬网、站位标签、指北针、比例尺和比例尺位置。分区填色还可切换连续、五级等距或五级分位数；矢量图可调展示长度倍数，保留原速度和速度色标。

原始坐标明确为 WGS84 / EPSG:4326，顺序为 `[longitude, latitude]`。投影使用 [pyproj Transformer](https://pyproj4.github.io/pyproj/stable/api/transformer.html)；等距圆柱的标准纬线 40°、中央经线 16°，Web Mercator 为 EPSG:3857。原生轴的 X/Y 是投影平面米，刻度文字显示经纬度；地图范围专用输入直接使用度。切换投影会移除旧投影下手动的 X/Y 轴范围，重投影底图、点、标签、栅格边界、等值线路径、流向及矢量端点。不会重新采样、重新统计或改变原始数值。

比例尺在其显示纬度用 [WGS84 椭球距离](https://pyproj4.github.io/pyproj/stable/api/geod.html) 求端点，不以经度数或投影平面距离冒充真实千米。未手动指定长度时，缩小范围会选择能放下的合适长度；明确指定且超出范围时拒绝保存，提示减小长度或改变位置。Mercator 的比例随纬度变化，单个比例尺只代表其所在纬度，不表示整幅图等距离。矢量展示端点用东西/南北速度、公共时长和测地线求解；流向路径为测地线；轨迹按保存的观测顺序连接，不推断时间插值。

地图保持投影平面的等比例显示，不能为凑齐组图宽高任意拉伸。此版本支持不跨日期变更线、经度跨度不超过 100°、纬度在 ±80° 内的区域地图；全球、极区、跨日期线或斜轴投影应扩展源代码及边界裁剪、经纬网和指北针计算，不强行套用当前选项。

对象样式及自由拖动属于展示编辑，不能声称改变真实地理坐标；修改实际站点或路径时由 Codex 修改来源经纬度并重新导入。地图数据排除通用 XY 回归推断。改变 CRS、插值、缺测掩膜或区域统计必须使用用户确认的分析方法。

## 真实数据接入

| 图型 | 原始输入及含义 |
|---|---|
| 位置与采样点地图 | 经度、纬度、站位 ID；可选组别与点形，标签与站位共用坐标。 |
| 分区填色地图 | Polygon/MultiPolygon、稳定区域 ID、数值；明确分级边界、缺失值和区域名称匹配。 |
| 比例符号地图 | 经纬度、非负大小变量、颜色变量；点面积与计数成比例，不能误用半径。 |
| 空间栅格地图 | 经/纬坐标轴或网格、二维数值数组、网格中心/边界定义和缺测掩膜。 |
| 空间等值线地图 | 显式网格和场、等值级别；离散站点需要另行明确插值方法，模板不自动推断。 |
| 空间矢量场地图 | 经纬度、东向/北向分量及单位；若原数据为投影网格或其他方向基准，先转换分量。 |
| 空间流向地图 | 起止节点坐标、方向、非负流量或权重，测地线或用户给定实际路径。 |
| 轨迹地图 | 经纬度和明确顺序/时间；不同对象和中断轨迹分段，不能跨缺失段自动连接。 |

地图依赖 `pyproj>=3.6`，由 `scripts/setup.py` 安装到本 skill 的本地依赖目录。项目复制运行模块与底图数据，保存后可独立复现；不同机器仍需安装声明的 Python 依赖。

# 箱线细节与图型画法（v1.0 开发版）

## 操作入口

“数据与图形”层选择一个柱或箱，用“当前柱宽 / 当前箱宽”改变单个对象的宽度。单位是分类方向的数据坐标单位；水平图修改高度方向的厚度。中心保持，误差线仍对准柱中心，箱体、中位线、须线与端帽一起调整。单箱宽度优先于本轴默认箱宽。已有轴范围不自动放大；对象超出画框时手动调整坐标轴范围或坐标框尺寸。

“误差与区间”层提供独立误差线颜色、线宽和不透明度，范围选择当前观测或所属系列。系列数据配色只修改数据主体与相应图例；误差杆及端帽保持独立样式，位置仍跟随。组合误差图例中，明确修改图例符号仍可能同时改变符号内的杆与帽，这是图例符号设置，不回写数据区间。

箱线图在数据层提供画法、箱体和样本点样式；误差层修改中位数、均值、须线及端帽。细节修改范围可选当前箱或本轴所有箱。组件选择按当前层过滤，对应锁定层阻止直接修改。细节颜色、透明度和线宽不依赖箱体填充。

箱线细节底部提供“编辑中位数、均值与须线”与“返回箱体与样本点设置”快捷入口，切换后保持当前箱，不占用撤销次数。

## 箱线图选择

| 选项 | 行为 |
|---|---|
| 点显示 | 原脚本、不显示、全部样本、仅箱外点、仅须外离群点 |
| 中心 | 原脚本、中位数、平均值、两者、不显示；均值可用菱形点或线 |
| 箱区间 | 原脚本、Q1–Q3、10%–90%、5%–95%、均值 ± 样本标准差 |
| 须线 | 原脚本、1.5 × 当前箱跨度内最远样本、最小值–最大值、5%–95%（覆盖箱区间） |
| 其他 | 四分位箱可选凹口；默认宽度、单箱宽度、点的横向散开 |

箱外点按选定箱边界筛选，离群点按选定须线筛选。标准差使用 ddof=1；单样本标准差按 0 展示。点横向散开由固定种子生成，只改变分类方向显示位置，样本测量值不变。不把自定义百分位箱误称为标准四分位箱；导出图题 / 图注应说明使用的统计区间。

凹口使用捕获的中位数区间；选择标准四分位重算时使用 Matplotlib boxplot_stats 的区间。缺少原样本和区间时拒绝添加凹口。统计计算选择不会修改数据源、分析结果或捕获快照。

内置论文版箱线模板的默认说明随箱区间、中心统计量、须线和点显示更新，示意数据标识按实际字号与面板高度避开两行说明。只更新精确匹配的内置默认说明；导入图及用户自定义图注保留原文。

## 原始样本接入

导入 Python 源码时，在原绘图执行期间拦截公开 Axes.boxplot / bxp / violinplot 调用，保存样本、统计量、方向以及组件关系。不执行第二遍源码。直接 bxp 的摘要统计量通常没有原始样本：能改细节、宽度和已有统计量显示，不能虚构全部点或重算区间。Seaborn 等封装若只传递摘要，也须由源码适配补上真实样本。

旧版本生成的已知演示 / 数据集箱线图和小提琴图，按已保存来源重新读取输入，并核对捕获几何后补上关系；只处理来源、种子 / 数据哈希可核对的图，不替换缓存。其他旧导入图需要重新导入原始绘图源码以接入统计选择。SVG / R 图须由原语言适配器提供样本及组件语义；不从图片四分位形状倒推样本。

普通 Matplotlib helper 使用示例：

```python
from apply_style import apply_fam_style, capture_plot_inputs
with capture_plot_inputs():
    fig, ax = plt.subplots()
    ax.boxplot(real_samples, patch_artist=True)
apply_fam_style(fig, figure_id)
```

完整重放使用项目 reproduce.py；它直接读取捕获的样本和图对象，也包含逐点 SVG 样式、组图和对象覆盖。

## 其他图型

内置图型提供常见显示选择，保留原有计算：柱图原脚本 / 簇状 / 堆积 / 百分比 / 簇状堆积；折线原脚本 / 线点 / 仅线 / 仅点 / 前中后阶梯；饼图与环形内圈；热图插值与单元格数值；小提琴点叠加、均值、中位数、极值；直方图填充或轮廓；散点、气泡、PCA 和三维散点实心 / 空心；PCA 零值参考线；VK 区域与标签；树图末端标签；森林图端帽；曲面和等值区间边线。原有点形、大小、色带、相机与 Newick 控件继续使用。不能从展示选择自动推算新的统计模型、核密度方法、树模型、分箱或插值数据。

## 设置字段

- `native.entities[ID].barWidth / boxWidth`：单个柱 / 箱宽度。界面批量操作为同类元素分别写入此值，可覆盖此前的单独宽度；不更改统计值或原始数据。宽度范围默认是当前坐标轴的所有同类对象（包括隐藏对象），可选同系列或单个对象。不同坐标轴的单位可能不同，因此不跨轴或跨组图面板扩散。
- `ui.widthScope=axis|series|current`：数字输入和鼠标手柄共用的宽度编辑范围，随项目保存。两侧方形手柄保持中心；横向图调整上下厚度。坐标轴范围变化后按当前变换换算宽度，支持线性、对数与反向轴；其他坐标变换使用数值输入。每次拖动只记录一次撤销。
- `native.entities[ID].errorStyle={color,alpha,lineWidth}`：同一观测的误差杆和端帽。集合中只改对应的误差段；SVG 中按实体给端帽设样式。精确输出用 reproduce.py。
- `native.boxPlots[轴索引]={points,center,meanStyle,range,whiskers,width,jitter,notched}`。
- `native.boxStyles[箱体 Artist ID][median|mean|whisker|cap|points]={color,alpha,lineWidth,markerSize}`。
- `native.plotVariants[轴索引]`：图型显示选项，字段按当前图型提供。

`distributions.py` 与 `variants.py` 随项目 runtime 复制。重建保持原箱体 ID 和旧组件 ID；新增均值等使用稳定派生 ID。组图细节复位用嵌套 `reset:true` 阻断来源图同组件覆盖，其他设置保留。保存、10 次撤销、恢复原始图和高质量导出沿用工作台流程。

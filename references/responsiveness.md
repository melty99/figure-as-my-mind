# 响应速度与缓存边界

预览按图形内容缓存，逐面板检查共用请求；图形、来源版本、尺寸、样式或原生设置改变时使用新键，强制刷新绕过缓存。组图位置单独同步到现有SVG，不将上次位置当新布局。缓存有数量和内存上限，完整对象关系仍可按需读取；无实体的图不能用空列表声称批量选择成功。

普通展示平移使用逐帧SVG预览，点及其误差、绑定标签、父柱的关联观测同步。不会从像素改写原值。网络边、配对边、区间顶点、共享树顶点、框缩放和真实三维仍按明确语义计算；不能把整条关联边平移当成移动其中一个端点。松开后由原生后端验证/保存；取消、失败、切换对象清除临时变换。检验中途和保存后的屏幕位移，不能只看选中轮廓。

纯界面保存只复用已验证且未变的科学设置，保持原始数据检查和修订冲突保护。完整设置和最多10步历史保留，JSON可紧凑序列化；原子替换和文件锁重试不变。合并面板时返回独立的有效设置，不共享可变源字段。路径缓存检查目录身份及重解析点，文件变化/缺失和保护清单改写仍拒绝，导出/数据校验仍强制核对哈希。

图片编码使用导出请求时的完整状态快照；生成PNG/PDF/TIFF期间允许继续编辑，后续修改不进入该次文件或代码包。Matplotlib相关计算依然串行保护，文件导出相互串行避免覆盖竞态。图形计算和高像素输出有实际成本，不能声称所有图型、分析或首次组图都瞬间完成。

性能验证采用相同真实来源图、项目大小、浏览器、画布和动作；计时不与全量回归争用CPU。分开报告首次生成、已缓存切换、对象准备、实际拖动帧和完成保存。优化交付前核对科学语义、无效设置、来源保护、缓存失效、撤销重开、导出期间保存及请求时快照。

稠密图的误差线段、端帽、区间路径和逐点点形每个集合只初始化一次，避免每个观测重新复制整组几何。SVG从属标签的归属判断也按集合复用。3,005个真实来源观测的全选、全部透明度修改、整批撤销、末尾对象选取和重开均需保留完整结果；性能上限只约束元数据初次载入与选择轮廓显示。

Windows后台服务停止需要等待自身稳定进程句柄发出退出信号；只轮询退出码可能早于日志文件释放。重启只操作经项目路径和服务命令核对的本skill进程，保留当前项目与可用URL。

共享图例/色标位置与设置进入图形缓存键，变更和撤销不能复用错误的布局。安装资源更新时，其他项目未重启的旧服务若缺少批量读取接口，前端仅探测一次后使用原逐面板协议，不为更新本skill停止其他项目服务。


2026-10-14 增加完整历史记录共享、无损缓存压缩、只读组图复用及按需布局写入，详见 [resource-efficiency.md](resource-efficiency.md)。

自动切换未标记 R / SVG 文字到自由编辑层时，只构建最终对象的属性面板，避免同一次按下重复构建。长按框选以实际输入事件时间判断；界面繁忙时不能由计时器抢占已排队的早期移动，慢速拖动开始后停顿仍保持该对象的操作。

## 单一组图范围与侧栏内缘（2026-10-17）

图件库“查看范围”一次只保留一个组图家族：显式选择的组图优先，打开成员图时保留其已打开的家族，否则按稳定顺序选择一个在用父组图；不把共享同一张图的多个组图合并，也不把已删除组图计入。前后端使用同一上下文发送 `composition`，缓存清理和组图家族保持一致。切换范围不写项目、不新增撤销、不重建来源；共享单图只保留自身与所选组图的缓存。

桌面侧栏内缘为 14 px 宽的实际可聚焦分隔条（`role=separator`、`tabindex=0`），拖动使用 pointer capture 与每帧一次 rAF 写入 CSS 变量，结束一次重排画布；双击、Enter、Home 重置，方向键 16 px、Shift 48 px、End 到当前上限。宽度只写浏览器 localStorage，不触发项目保存、SVG 重绘或撤销；窄窗口隐藏分隔条并改用抽屉，Esc 关闭。调整宽度只重排预览，不改变图内对象、来源或导出尺寸。

并重复核：侧栏调整期间不应出现 `/api/view`、`/api/save` 请求；既有稠密图首次生成仍需约 20–26 秒，缓存复开与切换可能受内容、浏览器和机器状态影响，不能据此宣称所有切换普遍加速。已测收益主要是缓存体积（约 18.6 MB → 3.5 MB），不是统一耗时下降。


## 逐张处理复杂组图

逐张模式的子图阶段只渲染选中的子图，通过与整组相同的 panel_record 路径生成；进入布局阶段才渲染当前整组。后续组图不提前渲染或读取捕获。字体等通用格式联动只比较轻量设置；修改派生分类系列时，才在当前组内读取必要的语义关系，以名称、图型和轴角色唯一匹配，不按不同捕获里的相同对象编号套用。

保存只检查发生变化的组及其来源；锁定的未变化组不再重复合并。工作流导航具有独立的修改序号，旧保存响应不会覆盖刚选中的子图；在保存过程中继续编辑时，仅合并用户未再次修改的后端系列样式，保留最新的本地设置。旧项目缺少子图标识时先在内存补足，正常用户保存后保留；只读打开不改原项目文件。

实际耗时仍取决于单张子图的矢量复杂度；不能把图件较少的合成示例时间当作所有科研图的速度保证。两侧分隔条拖动是本地布局变化，不在拖动中发起绘图或保存请求。

## 精确重绘中的手柄挂载

完整 draw 在最终元数据、参数栏与子图几何更新后统一挂载交互控件。其内部 fitPaper 仅计算预览尺寸，避免重复创建图层与组图手柄；单独的缩放和窗口尺寸变化仍更新全部控件。单图实际重绘探针从每次两次图层挂载降为一次，保留八向手柄；并发功能检查期间的耗时仅作诊断，不作所有图型的速度保证。

联动锁定等不影响画面的刷新复用当前检查信息及已绘 SVG；身份或视觉签名改变则失效。实际检查锁定不增加绘图请求，真实格式修改仍重绘，不能用复用省略来源校验或隐藏控件。

同一防抖窗口内的科学外观修改与进度 / 锁定保存合并时，保留已排队的重绘需求；不能让后来的 render:false 进度更新覆盖 render:true 的字体或颜色变更。显式导航 flush(false) 仍可省略离开前的旧画面重绘。已完成组图再次精修、撤销 / 重做及重开需保持画面与保存设置一致。


## 自动适配显示器与窗口（2026-10-20）

按浏览器的实际 CSS 视口宽高排版：系统显示缩放和浏览器缩放已体现在可用宽高中，不按 screen.width / 物理分辨率再缩放整页。默认左右侧栏宽度随窗口增长并设上限；用户宽度偏好与实际可显示宽度分开，缩小窗口仅临时收窄，放大后恢复原偏好，不把临时宽度写回 localStorage。恢复默认后重新使用自动宽度。

高度不足时压缩栏头、空隙和重复图层入口，保留相同图层下拉；左右栏内部滚动。顶部因中英文、字体或窗口变化而换行时，ResizeObserver 测量真实高度，工作区据此留位。提示条在各布局密度内预留固定高度，选中对象出现操作按钮时不挤动图件。1100 px 以下图件库改抽屉，760 px 以下调整栏也改抽屉；窄屏打开对象编辑器时，预览和编辑区上下排列，仍可同时观察。

图形预览仅重算纸张的显示尺寸，保留用户预览缩放倍数。ResizeObserver 与侧栏重排按动画帧合并；窗口操作不发出保存或重新渲染请求，不更改项目、撤销、图内字号、坐标、物理尺寸或导出 DPI。不得用应用层 transform / zoom 使鼠标位移与图件坐标失配。

三维临时 Canvas 按 devicePixelRatio 分配显示分辨率；监听 resolution 媒体变化，并在窗口 resize / focus 时复核。相同尺寸不重复分配 backing store；仅在三维编辑开启时保留这些监听，关闭时完整清除。精确 SVG 和科学几何保持原值。

验证覆盖 18 种有效视口、常见 125% / 150% / 200% 设备缩放、中英文、侧栏宽度往返恢复、文字草稿、实际拖动、组合与逐张编辑，以及真实 R 分面接入。设备缩放在浏览器环境中模拟；无头 Chromium 的 CDP 仅改 DPR 时不派发显示变化事件，因此三维换屏检查另派发 resize 信号，验证相同 CSS 尺寸下 backing store 随 DPR 更新；未冒充实体多显示器测试。

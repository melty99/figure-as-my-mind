# 拟合、相关分析与置信区间

在“数据与图形”层展开“拟合、相关分析与置信区间”。用于含原生二维 XY 坐标的折线、散点和误差点图；三维投影、无数据 SVG 和位图须先接入原代码及数据，不能从屏幕位置推算统计输入。

## 输入和显示

可选择一个或多个实际系列，并选择逐系列分组拟合或合并系列整体拟合。轴之间不自动混合数据；组图面板的拟合设置独立保存，不回写来源图。

原始数据保护启用后固定从捕获时的坐标计算。拖动或隐藏点仅修改展示，不改变源数据、拟合或相关分析；隐藏点仍参与原统计，旧设置的 display 请求也改为原始输入。非有限坐标被排除，摘要记录排除数量。图形中的坐标不一定是原始实验样本：对已有汇总曲线或估计量，需要按原分析设计确认这些输入是否适用于回归，不能把曲线采样顶点当作新增独立观测。

论文版折线模板明确关联一条示意模型曲线与其观测点。改为“线与点”“仅线”或阶梯折线时使用观测点，不再同时连接模型曲线采样点。原脚本画法保留曲线与点。拟合使用每组 9 个示意观测，不使用每条模型曲线的 100 个采样顶点。论文版散点模板使用每组 36 个示意观测，不使用原 OLS 曲线顶点。

拟合默认隐藏已识别的原示意 / 拟合曲线，并展示“观测点 + 拟合线”。可保留观测折线、观测原画法或仅显示拟合。来源未知的自定义模型线不按颜色随意识别；添加明确的 `_fam_series_line` 关联，或者在原脚本中删除旧模型线。仅已知论文版散点模板可恢复其旧缓存中未显式保存的曲线与色带关系。模板中关于原拟合方法的精确说明跟随新方法更新；不改写导入图的论文标题、注释或源文件。

“仅显示拟合”同时隐藏所选观测的误差杆和端帽，未选择系列保持原画法；切回观测显示可恢复。未命名散点及带标记折线不会因旁边有命名系列而从候选中消失，但普通未标记匿名曲线在有命名观测时不自动作为新增观测。两个不同 X 的观测可在关闭区间时确定直线；需要残差方差的置信区间仍要求足够残差自由度。缺失配对计数与有效观测缓存分别核对，避免不同输入共用错误的排除数量。

## 方法和区间

| 方法 | 选择 | 区间计算 |
| --- | --- | --- |
| 普通最小二乘直线 OLS | 估计截距 / 强制通过原点 | Student t 点态均值区间 |
| 加权最小二乘直线 WLS | 正的对称 Y 标准差；权重 1/σ²；截距选择 | 相对 σ 由残差估计整体方差，用 Student t；已知绝对 σ 用未缩放协方差和正态分位数 |
| Huber 稳健直线 | 截距选择；Huber 阈值 1.345，MAD 残差尺度 | 固定 X 的 wild 残差 bootstrap 百分位近似点态均值区间 |
| 多项式 | 2–5 阶，包含常数项 | Student t 点态均值区间 |
| LOESS 局部平滑 | 窗口比例 0.1–1；局部直线 / 二次曲线；0–3 次稳健重加权 | 固定 X 的 wild 残差 bootstrap 百分位近似点态均值区间 |

LOESS 用最近邻窗口、tricube 距离权重和局部多项式；稳健迭代采用残差 bisquare 重加权。若零权重造成窗口中缺少有效支撑，扩大窗口到足够多的不同 X 值，避免返回零值的伪结果。这里的实现是本工具的局部拟合，不宣称与 R `loess` 或 statsmodels LOWESS 每一项默认设置完全一致。方法依据见 [NIST LOESS 说明](https://www.itl.nist.gov/div898/handbook/pmd/section1/pmd144.htm) 和 [statsmodels LOWESS 参数说明](https://www.statsmodels.org/stable/generated/statsmodels.nonparametric.smoothers_lowess.lowess.html)。

置信水平可设 50–99.9%，默认 95%。这些都是每个 X 位置的拟合均值区间，不是新个体的预测区间，也不是整条曲线的同时置信带。OLS / 多项式区间按独立、同方差的正态误差模型计算；WLS 要求 σ 的解释与模型一致。不要将 SD、SEM、置信区间半宽混作同一种 σ。重采样假设观测独立；有同一受试者重复测量、聚类或时间相关时，应从原分析脚本接入相应模型和区间。

Huber / LOESS 区间采用中心化残差乘独立 ±1 符号，每个重复重新拟合，再取预测分位数。默认 200 次，可选 100 / 500 / 1000；固定 seed 保证保存、重开和复现一致。区间近似且未作平滑偏差校正，尤其 99% 等尾部区间应增加重复次数并检查稳定性。点态覆盖不能从一张演示图认定。

所有方法只在所选有效观测的 X 范围内绘制，不外推。摘要 n 为参与拟合的有效坐标数，系数按常数项至高阶排列，R² 为原 Y 上的中心化描述值；强制通过原点时也沿用此定义，可能为负，不等于部分统计包给出的未中心化 R²。LOESS 没有全局回归方程。

## Pearson / Spearman 相关分析

相关分析与回归拟合可独立开启，也可同时展示。Pearson 衡量线性相关，Spearman 衡量秩的单调相关；二者不产生新的回归曲线或回归方程。选择一种或同时选择两种，按每个系列或合并的有效配对 XY 计算，并在图中显示 r / ρ、双侧 P 值及 n。Spearman 对并列值采用平均秩，常量输入显示未定义及原因，不编造零相关。方法和解释见 [SciPy Pearson](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.pearsonr.html) 与 [SciPy Spearman](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.spearmanr.html)。

P 值默认自动选择：Pearson 使用 SciPy 参数检验；Spearman 在 n≤500 时使用置换，在 n>500 时使用渐近近似。也可显式选择参数 / 渐近或置换。置换在 n≤7 时枚举全部配对排列，较大样本以固定 seed 随机置换 Y，按绝对统计量计算双侧尾部概率；Monte Carlo 使用 `(极端次数+1)/(重复次数+1)`，不报告伪零 P 值。可选 999 / 9999 / 49999 次（默认 9999）；n×重复次数超过 2500 万时拒绝执行并提示减少次数或选择渐近法。标签和结果说明实际采用的方法。

参数检验依赖相应的独立观测和分布条件；置换要求零假设下配对可交换。工具不自动处理重复测量、聚类、时间依赖或多重比较。合并系列可能改变相关方向和大小，应按研究设计选择分组。相关分析不使用 WLS 权重，也不因选择某个回归模型而改变其定义。仅开启相关分析保留原观测和曲线的画法。

## 拟合公式和统计文字

开启 OLS / WLS / Huber / 多项式拟合后勾选“在图中显示拟合公式”，按实际拟合系数生成 `y = …`，有效数字可设 1–8 位。公式会随模型、观测和分组更新；LOESS 由局部模型组成，没有单个全局回归方程，因此该项不可用。相关系数和拟合摘要仍可独立显示。

展开“公式和统计文字的位置与格式”，选择某组的方程、相关分析或摘要，修改字体、字号、粗细、斜体、颜色、透明度、旋转、对齐、背景和位置。也可直接点击文字进入注释层并拖动；框选多个公式按相同屏幕距离移动。位置以所属坐标框比例保存，允许移到坐标框外；调整坐标框或组图面板大小时跟随所属轴。改字号不重新做统计计算。

设置保存在 `native.fitLabels[标签ID]`，含 `position: [x,y]`、`fontFamily`、`fontSize`、`fontWeight`、`fontStyle`、`color`、`alpha`、`rotation`、`horizontalAlignment`、`verticalAlignment`、`background`、`backgroundAlpha`、`visible` 等字段。标签 ID 由轴、文字类型和来源系列生成；切换系列子集不会把 Group A 的格式套到 Group B。统计内容由模型生成，不能把自动方程直接改成与数据无关的文字；自定义说明使用独立文字装饰。

“复位当前统计文字”恢复该标签的默认格式和位置，保留其他标签；组图面板复位只作用于该面板。支持 10 步撤销、自动保存、重新打开及 SVG / PNG / PDF 导出和脚本复现。锁定注释层禁止直接修改这些文字的显示和格式，数据改变引起的必要内容更新仍跟随；锁定数据层后仍可在未锁定的注释层调整文字。

## 保存、外观和性能

拟合线可沿用系列颜色或统一选择常见 / 自定义颜色，设置线宽、线型、不透明度，区间透明度独立。摘要可在图中显示，并随全图字体与注释层格式更新。拟合线、区间和摘要分别归入数据、误差与区间、注释层；缩放坐标区域时跟随映射。锁定数据层禁止直接改拟合；锁定误差层禁止直接改区间水平、透明度和重采样设置，但数据模型改变引起的必要区间重算仍跟随。

计算结果按观测值、σ 和统计参数缓存（最近 32 项）；只改线色、透明度或字号不重新进行 bootstrap。无稳健迭代时复用固定 X 的局部线性算子，批量计算 bootstrap，与逐次重新拟合数值一致。LOESS 单组上限 10000 点，带重采样区间上限 1500 点；稳健区间另检查点数 × 重复数 × 迭代量，过大时明确要求减少重复 / 迭代或由原脚本计算，不阻塞界面并且不静默抽样。

设置位于 `native.fits[轴序号]`，随项目、设置复制与 `reproduce.py` 保存。`apply_style.py` 也调用原生调整入口，要求目标图有对应语义系列；系列 ID 不按不同图中的相同字符串推定为同一实验组。

```json
{
  "fits": {
    "0": {
      "enabled": true,
      "method": "loess",
      "scope": "grouped",
      "input": "original",
      "span": 0.6,
      "localDegree": 1,
      "iterations": 0,
      "ci": true,
      "level": 95,
      "bootstrap": 200,
      "seed": 20261007,
      "dataDisplay": "points",
      "replaceOriginal": true,
      "colorMode": "series",
      "lineWidth": 1.8,
      "lineStyle": "--",
      "alpha": 1,
      "bandAlpha": 0.18,
      "showSummary": false
    }
  }
}
```

可选 `series` 为当前轴参与拟合的语义系列 ID 列表；省略时选择可用系列。`color` 设置整体或自定义拟合线颜色，`bandColor` 可通过复用设置指定独立区间颜色。WLS 使用 `weights: "relative" | "absolute"`；直线使用 `intercept`；多项式使用 `degree`。无效参数、缺少所需观测或权重时拒绝保存并保留上次有效状态。

同时显示线性方程和两种相关分析，可在该轴的 `fits` 中设置：

```json
{
  "enabled": true,
  "method": "ols",
  "scope": "grouped",
  "showEquation": true,
  "equationDigits": 4,
  "correlation": "both",
  "correlationP": "auto",
  "permutations": 9999,
  "showCorrelation": true
}
```

`correlation` 可设 `none | pearson | spearman | both`；`correlationP` 可设 `auto | asymptotic | permutation`。仅相关分析使用 `enabled: false`，保留 `correlation` 选择即可。相关计算独立缓存最近 64 项，文字位置和外观调整复用数值结果。

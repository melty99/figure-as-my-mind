# 打开前适配三维与分层地图

## 识别真实编辑能力

先看原语言代码、声明数据、捕获的 axes 和色标。图看起来立体，不代表保存了 XYZ 相机。仿射二维地图叠层、平面 SVG、WebGL 截图需要找到生成代码与明确几何；不要为显示 3D 控件而猜测观测深度。普通 PNG/JPG 仍按先重画再接入处理。

```powershell
python <skill>/scripts/studio.py --project <project> import-python <source.py> --require-3d
python <skill>/scripts/studio.py --project <project> check-editability --require-3d
python <skill>/scripts/launcher.py --project <project> --require-3d
```

严格接入在保存源快照 / 图件前检查；检查失败先适配，不交付一个仅能打开而不能完成预期编辑的链接。普通二维接入无需此选项。检查报告给出相机、坐标轴、色标和未支持几何，不替代实际鼠标操作及导出验证。已有旧项目要核实捕获与源码，保留用户设置；在任务工作副本中适配，不覆盖原研究工程。

## 明确图层的地图桥接

`scripts/planar3d.py` 的 `ImagePlane3D` 在原生 Matplotlib 3D 轴上显示原标量网格，保留网格值、缺失掩膜与颜色映射；海岸线、等值线、采样点、标题和色标仍是独立对象。相机、缩放、平移及 X/Y/Z 范围使用原生坐标；透视输出通过单平面反向投影重采样绘制，拖动使用本地轻量纹理与向量预览，松开生成精确 SVG。此桥接不重新进行插值或统计计算。

对于有明确仿射投影和图层偏移的捕获，可在原 Python 脚本里适配：

```python
from planar3d import convert_affine_maps
convert_affine_maps(fig,
    bounds=[x_min, x_max, y_min, y_max],
    matrix=declared_2_by_2_matrix,
    offsets=declared_layer_offsets,
    scalar_label='Value (unit)', mapping_id='shared-field')
```

`bounds`、矩阵和偏移必须来自原代码。函数校验每个地图对象的变换是否与声明一致，不匹配则拒绝。它面向带标量网格、等值线、地理点与多边形的平行地理图层，不是任意画面的自动三维恢复器。层间距为示意时保留该声明；不能称为实测水深。重跑脚本时把 skill 的 scripts 或项目 runtime 加入模块路径，并保留原脚本、输入和该适配声明。

同一变量跨图层 / 季节共享色标时使用同一 `mapping_id`；全部地图字段和图例共同改色，不把范围代理值当作原始观测。`promote_insets` 在捕获前将嵌套色标登记为可编辑坐标轴，保留原始位置；八向手柄保留足够点击间隔，细色条也可独立调整宽高。

## 分层地图先平面、再三维

明确地理边界与示意图层的地图新接入后先进入真实二维平面；已有项目不自动改动已保存视图，点击“1 · 返回平面编辑”进入。可选择底层或表层，各层采用原数组、掩膜、路径与观测，其他层暂时隐藏。坐标框采用可独立调整的宽高，数值输入与四边 / 四角拖动保持一致；范围、字体、颜色、色标和关联元素继续使用原生编辑。

点击“确认平面 → 3D”保存当前实际平面宽高（英寸），进入空间角、投影、缩放、平移和示意层间距调整。三维阶段使用确认后的平面比例，不提供会耦合透视投影尺寸的坐标框宽高拖柄；要改范围或宽高时返回平面。阶段切换、平面选择和确认可撤销，保存后可恢复，组图仅改变当前面板。平面设置与相机分别保存，原始捕获仍是不可改写的来源。

`native.spatial[axis]` 使用 `phase`（`plane` / `spatial`）、`plane`（图层索引）、`confirmed`、`planeSize`（确认时实际英寸宽高）及 `layerSpacing`（相对平面高度，默认 0.3）。缺少 `phase` 的旧项目保留三维显示。仅对明确声明地理边界与平行图层的桥接启用；普通散点 / 曲面等真实三维图沿用原生相机，不擅自压成平面。地理范围保持线性经纬度，不对地图套用对数尺度。

## 交付核验

至少操作真实来源图的相机、整图缩放、色标宽高和范围面板。核对裁剪后的海岸线 / 标量场 / 点一起更新，范围之外的几何不会触发空路径错误。取消不保存、应用一次可撤销，重新打开后设置保留；组图只修改目标面板。比较适配前后的全部标量网格、掩膜和采样点坐标，并保留原捕获哈希。分别记录首次打开、换图和拖动帧耗时，不把内核毫秒数当完整界面耗时。最后验证 SVG / PNG / PDF 输出与所需语言复现包。


## 三维坐标轴的位置一致性

拖动预览与精确渲染共用原生轴的边框选择、刻度位置、文字间距和旋转参数。按当前相机投影选择轴边，不以固定画布位置或简单象限近似；反向轴、滚转、非 Z 竖轴及正交 / 透视需一并核对。分层地图的默认轴框贴合声明的层平面，旧捕获的额外示意 Z 留白仅在未显式设置 Z 范围时兼容调整，不改捕获和原数据。自定义范围保持。

验证时比较拖动与松开后的刻度 / 轴名锚点，不能只验证数据点投影。`test_spatial_guides.py` 对照 Matplotlib 实际绘制坐标，覆盖轴线、刻度线、刻度文字和轴名；真实来源图另外检查拐角文字、组图和导出。


范围联动须区分框架与地理数据：声明的全图矩形边框、背景、角点连接线和相对层名锚点跟随新视窗重建；海岸线、等值线、采样点和标量网格按实际坐标裁剪，不被拉伸到新范围。旧桥接捕获通过原显式地理边界及排除观测标记兼容识别框架，不改变捕获。未显式指定的地图数值刻度随范围重新生成，用户设定的刻度与标签保持。验证包含扩大范围、缩小范围、反向轴、完全移出视窗、组图与从下方观看。


## 组图同步旋转

在完整组图视图中打开 3D，勾选“同步旋转本组未锁定子图”。默认关闭；只编辑一张子图的逐张视图保持单图操作。开启后，同时绘制兼容的原生三维子图，相机旋转方向一起更新；各子图的比例、缩放、平移、字体、颜色、色标、数据和来源保持。未锁定的独立子图仍可参与；“锁定联动”或坐标框层锁定的子图跳过。仅有一个明确原生三维坐标轴的其他面板可自动参加，多轴/未知专用几何不猜测关联。

实时预览不写原始单图，鼠标释放后生成精确组图 SVG。应用一次可整体撤销或重做；取消保持原设置，保存重开保留已应用视角。关闭编辑器后同步开关回到默认关闭。同步模式下“恢复三维视图”只将参加面板恢复到参考子图的原始相机，不重置它们各自的缩放、比例或字体和色标；要保留某张原有视角，先锁定联动。

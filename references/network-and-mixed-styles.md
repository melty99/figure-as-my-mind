# 组图对齐、混合样式与网络布局

v1.0 开发版，2026-10-10。

## 组图统一与对齐

“统一与对齐”也将选中的子图作为框尺寸和字体设置来源；共同坐标范围仍是单独选择。固定比例、三维、多个主坐标框和锁定框保持原布局；不足两个兼容框时明确说明。若基准框装不进其他子图容器，扩大目标容器或关闭尺寸联动，不悄悄缩小基准。

## 混合符号和线型

原图可能同一系列有多种点形、逐点颜色或不同面积，这些属性默认保留。控件会识别常见散点符号，无法识别的保留为“原自定义点形”，同一系列多形状显示“原系列含多种点形”。散点可以选择“仅当前点形状”，也可设置所属系列的统一点形；单点覆盖继续优先，复位当前对象恢复捕获时的点形。折线的点形按系列编辑。

数据层“系列与线段样式 · 分别编辑”可直接选择系列或线段，包括没有可拖动观测节点的线。设置颜色、不透明度、线宽、线型和点形；只改明确选中的系列。不同颜色编码不同变量时，不因排版适配而统一。连续色带保留数值映射。同一集合多形状的 SVG 点仍能准确逐点着色，图例按系列的显式编辑更新，不把一个特殊点的形状推广到整组图例。

“仅线”“线与点”和阶梯画法保留原来的虚线/点划线；原对象没有线型而要求连线时才补实线。误差杆继续独立配色，避免组色覆盖区间。

## 网络图规则

网络图数据层优先显示布局选项：

| 布局 | 规则与参数 |
|---|---|
| 原始布局 | 保留捕获的节点坐标 |
| 力导向 | 固定随机种子，权重平方根调节引力；可改斥力间距和迭代次数 |
| 单圆环 | ID、度数或分组排序后等角度放置 |
| 同心圆 | 每组一圈，组内按所选顺序排列 |
| 分组圆簇 | 各组分开成簇，组内圆环排列 |
| 谱布局 | 显式权重邻接矩阵的拉普拉斯特征向量；属于布局而非统计结论 |
| 网格 | 根据排序排成规则网格 |

布局旋转可独立调节。节点面积可选原始、等面积、按度数或加权度数。后两者为 `基准面积 × (0.3 + 0.7 × 值/最大值)`，设置下限保证低度节点仍可见；不应解释为从零起严格正比。点形可保留各组或按组分配不同符号；单节点点形覆盖优先。标签可用原始文本、ID、组名或隐藏。连边宽度可原始、统一或按权重；不透明度和显示权重阈值独立设置。

阈值只控制边的显示，不删除数据；度数、加权度和布局仍使用完整拓扑。节点拖动时，其所有关联边端点和绑定标签跟随；隐藏节点同时隐藏其关联边。节点输入 ID、分组和边权不因布局变化而改写。种子与参数随项目保存，导出和 `reproduce.py` 重放一致。模板脚注会更新展示规则，避免修改编码后沿用旧说明。

当前布局适配支持带明确节点/边数据的内置网络模板及其已保存实例；不从任意位图/SVG 的相交线猜拓扑。导入自定义网络需在源码保留节点表、零起点边索引与原生散点/线段映射。力导向的交互计算限制在 400 节点内；大网络在源码中预先布局。

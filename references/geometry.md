# 字体、轴、画法与适配（v1.0 开发版）

## 操作入口

- 字体下拉框包含 Times New Roman、Arial、Calibri、Cambria、Georgia、Verdana、Tahoma、Courier New、Segoe UI、DejaVu Sans/Serif、Microsoft YaHei、SimSun、SimHei；保留源字体和自定义字体族输入。未安装的字体明确标记，不默默声明已安装。
- 选择“刻度与网格”层，再选 X/Y/Z 和“坐标轴标题”或“刻度数字”。字体、字号、颜色、粗细、斜体分别保存。二维轴标题可直接拖动，或输入轴框比例 X/Y：0–1 是框内，负数可位于框外。Z 深度与真实 3D 相机仍使用三维面板。
- 选择“坐标框”层：四侧边框逐侧调整显示、颜色、线宽、外移；附加轴选择侧面、标题、颜色、字号、间距。换算模式明确为 `a × 主轴值 + b`，a 不能为零。独立刻度模式提供另一套范围；要把另一组数据画到该轴，需在源代码声明系列所属轴。同侧已有主轴刻度时默认外移 48 pt，可调整并点击适配补足留白。
- 单图的普通二维坐标框支持“绘图区宽 / 高（mm）”，设置实际坐标框尺寸，原坐标范围及点、误差的映射保留；固定比例、极坐标和三维仍使用其比例约束。画布尺寸默认毫米，可切换英寸，单位切换不改变物理尺寸、不占绘图撤销次数。非法或空白的已提交数字恢复为上次有效值，并提示原因。
- “文字与装饰”层的对象列表可按文字、类型或 ID 搜索；超过 700 项时可搜索定位后面的对象，筛选时保留当前选中对象。多行 SVG 注释使用 tspan 重放换行，字体、旋转和缩放仍可编辑；重新导入这类 SVG 后保留换行。
- 选择“数据与图形”层：柱图画法切换原脚本、簇状、堆积、百分比堆积、簇状堆积。簇状堆积按系列填写簇编号；相同编号堆积，不同编号并排。分类总宽度和空隙可调整。
- “复位当前对象”只恢复所选层的对象覆盖。数据层复位点的位置、颜色和宽度，保留独立的误差颜色、透明度与缩放；误差层仅复位误差参数。数据位置恢复时，误差几何仍跟随。独立注释复位保留坐标区标题。组图不回写来源；共享系列的颜色和位移需在所属系列中调整。

## 原始状态、撤销和颜色

“恢复原始图”恢复导入/首次生成时的真实捕获快照：全图格式、大小、透明背景、轴范围/位置/附加轴、图型布局、3D 相机、观测移动/颜色/隐藏、图例与新增注释均复原。输入数据和原代码始终保留。组图按当前子图恢复，来源单图和其他子图不变，布局仍由组图面板控制。恢复后的子图标记 originalBaseline，可继续独立编辑，关闭后保留。锁定层需先解锁。恢复是一次可撤销操作；“复位当前对象”只复位当前对象覆盖，不复原全图格式。

顶部按钮显示 `撤销 n/10`、`重做 n/10`，Ctrl+Z 和 Ctrl+Shift+Z 同样可用。第 11 次编辑挤掉最旧快照；换层、无变化输入和失败的前端输入不占次数。新编辑清除重做分支。会话重新打开后继续使用保存图，但内存撤销记录重新开始。

数据层选“联动观测对象”，设置“当前点填充色/边线色/不透明度”。“颜色修改范围”选择所属系列或仅当前观测；柱图默认所属系列，普通点默认仅当前观测。“当前所属系列”提供整组颜色与不透明度。系列按捕获的 BarContainer/曲线/集合建立，不能把单根柱子的 Artist 当成整组。最近一次明确的范围修改优先：整组改色会覆盖之前该组的点颜色；之后仍可单独改某个点。按数值映射的系列可单独改点显示，原标量数组和色标保留；批量时不能把某个点 ID 盲目套到不同变量。

图例层设置背景、边框、文字/标题颜色、背景不透明度，选“当前图例条目”分别修改符号颜色、符号不透明度和文字颜色。“图例改色范围”默认图例 + 对应系列，也可选仅图例符号。只对捕获关系中能唯一匹配的分类系列联动；重复名称、无对应关系或数值映射色带保持仅符号修改，不按相同颜色猜分组。数据区误差杆和端帽保持独立配色；在“误差与区间”层调整，不随数据主体系列颜色改变。组合图例的明确符号设置可同时改变图例内杆与帽。

按住图例中的文字、边框或无边框图例的空白处可以整体拖动。点击会自动选择图例层，点击条目文字同时选择该条目。原生图保存轴内锚点，拖动使用真实布局外框计算，避免无边框图例内边距造成初次跳动。拖动标题自动选择注释层；“标题所属区域”分别编辑整图总标题与坐标区标题。左、居中、右三种坐标区标题保留原位置，默认选择原脚本非空标题。坐标区标题按轴框比例保存，总标题按画布比例保存；字体、颜色、字号、显示与位置独立。语义 SVG 标题仍采用对象平移。锁定层阻止拖动；组图换序后仍按面板身份检查锁定，每次拖动是一次可撤销操作，组图只修改当前子图。

所有颜色框提供常用颜色下拉和自定义颜色拾取器，包括黑、白、蓝、红、绿、橙、紫、粉、青、黄绿、灰、棕、蓝绿、浅橙。不透明度 0 是全透明、1 是不透明。单点样式由最终 SVG 层按实体应用，支持线图、散点、数值映射和三维点；准确复现使用 reproduce.py。原生系列和图例颜色可由 apply_style.py 重放。

## 保存字段

```json
{
  "native": {
    "axes": {
      "0": {
        "labelStyles": {"x": {"fontFamily":"Times New Roman", "fontSize":16, "x":0.5, "y":-0.15}},
        "tickStyles": {"x": {"fontFamily":"Arial", "fontSize":10}},
        "spineStyles": {"left": {"visible":true, "color":"#2277bb", "lineWidth":1.5, "offset":0}}
      }
    },
    "secondaryAxes": {"0": {"right": {"visible":true, "mode":"linked", "factor":2, "shift":1, "label":"Converted value", "color":"#2277bb", "offset":0, "pad":4}}},
    "barLayouts": {"0": {"mode":"grouped-stacked", "width":0.8, "gap":0.12, "stackGroups":["1","1","2","2"], "autoRange":true}}
  }
}
```

`labelStyles`、`tickStyles` 支持 fontFamily/fontSize/fontWeight/fontStyle/color/rotation/visible；轴标题另有 x/y/pad。字号和外移单位为 pt，标签位置是轴框比例。轴角色、系列个数和分类对应关系在批量复用前核对；同一个 ID 不代表另一张图里同一个变量。

坐标区标题使用 `native.axes[索引].titles[left|center|right]`，每处分别保存 text/position/pad/style，保留三处独立设置；`titleLoc` 指定界面当前编辑处。旧的 title/titlePosition/titleStyles 字段仍可重放，界面编辑时迁入对应标题处。编辑侧标题不会额外创建居中标题。总标题使用 `native.figureTitle`，字段为 text/position/fontFamily/fontSize/fontWeight/fontStyle/color/visible。组图对象复位的内部标记 `resetData`、`resetTitle`、`titles[位置].reset`、`figureTitle.reset` 用于屏蔽来源覆盖，按 `resolve_panel` 解析；批量绘图不要复制复位标记。

点边线及误差帽的 SVG 共享定义按有效样式复制并复用；颜色、透明度和帽线宽同时作用于引用及定义，避免原始 marker 的显式样式盖过编辑设置。相同样式的千个点复用一份定义，避免逐点复制造成膨胀。

柱图只自动处理由 Matplotlib BarContainer 声明、分类数量相同且方向一致的系列。正负值分别堆积。百分比模式以各类别的绝对值总和归一化，保留正负符号；各段误差按对应比例缩放，不把某一段误差称为整根累计误差。已有显式轴范围优先于自动范围。复杂嵌套分类、缺失分类或其他原语言的画法由源码适配，失败不覆盖最后有效状态。

## 性能与接入范围

编辑器合并 SVG 与属性读取，请求使用同一份渲染；渲染 LRU 上限 128 项 / 64 MiB，组图面板缓存上限 128 项 / 32 MiB，样式/几何/尺寸/导出 DPI/源文件时间变化会使缓存失效。保存校验产生的渲染继续供预览使用；保存状态不变时不额外写修订。SVG 绘制使用单次绘制，拖动最多一条预览请求在途，新位置替代排队位置。缓存不等于超大数据绘图始终实时。

这些原生轴、柱图画法及适配使用 Matplotlib 语义对象。普通 SVG、R 和其他语言保留通用格式与已声明的联动协议；上述原生参数需相应语言的源码适配。位图需重建数据语义。examples/multi-language-workflow 的八种 R 图已实际从 CSV 作图、接入并验证编辑和导出；这不意味着未知 SVG 自动获得未声明的统计与联动关系。

依据：Matplotlib 的 [Axis.set_label_coords](https://matplotlib.org/stable/api/_as_gen/matplotlib.axis.Axis.set_label_coords.html) 和 [Axes.secondary_yaxis](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.secondary_yaxis.html)。浏览器验证使用 `scripts/v13_qa.py --round 1..5` 的独立项目，覆盖对象移动/重置、字体/标题、适配、柱图画法/组图、边框/附加轴/导出。

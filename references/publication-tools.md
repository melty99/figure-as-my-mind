# 论文参考版图库与科研工具

v1.0 开发版。73 种单图模板，新建默认 `single-v3`；原项目的 `single-v2`、`paper-v1`、`legacy` 按捕获版本复现，不能用新版替换用户已有设置或输入。

`scripts/design_references.json` 为每种图型保存视觉参考、方法参考、版式特点与使用说明。画布下方“科研工具… → 参考样式”提供链接。来源图片只供参考；新模板为独立绘制，合成数据不作为论文证据。沿用原数据图的数值、统计定义和结构；透明背景、较细坐标线、字体层级、留白与图例简化属于展示调整。

## 新增图型与输入

| 图型 | 需要的真实输入 / 当前示例方法 |
| --- | --- |
| 雨云图 | 样本值与分组；半 KDE、原始点、四分位箱 |
| 配对变化图 | 同一 ID 的两次观测；一个点移动仅更新对应连接端点 |
| 效应量估计图 | 成对差值；固定种子 3,000 次重采样、95% 百分位区间 |
| 六边形分箱图 | 原始 XY；更改分箱数重新统计计数，不复制观测 |
| 相关矩阵图 | 有限完整行；Pearson 系数，保留 n；可显示下/上/完整矩阵 |
| PCA 双标图 | 原矩阵与预处理；样本 SD 标准化、SVD、得分与注明显示倍数的载荷 |
| MA 图 | 平均丰度、真实效应值与校正 P 值；示例 Welch / BH，不冒充 DESeq2 |
| 决策曲线图 | 二元结局、预测概率、阈值；TP/FP 净获益与 treat-all / none |
| 累积发生率图 | time、event=0/1/2 与组；Aalen–Johansen，竞争事件保留 |
| 列线图 | 已确认模型、变量范围与系数；当前为显式合成 logistic 模型 |
| 多轨道环形图 | 同一扇区的多条数值轨道；共同归一化与色标 |
| 区间轨道图 | 起止位置、方向、同坐标信号；不由图片推断区域注释 |
| 堆叠点图 | 原始值、分组、分箱宽；每个点是一条观测，更改宽度重新分箱 |
| 哑铃图 | 同一类别的两个明确数值；两端独立编辑，连接线端点跟随 |
| 马赛克图 | 列联计数；矩形面积为计数占比，可切换计数标签 |
| 平行坐标图 | 同一 ID 的多变量向量；可选择各列 min–max 标准化或原值，保留原始数值 |

新图型是目录类型，尚未接入通用 CSV 批量生成器的图型由 Codex 根据明确的输入与统计方法编写 R / 用户指定语言脚本，再导入工作台。曲线顶点、载荷箭头、环形格子和区间形状不能冒充独立原始观测用于拟合。

## 已实现操作

- “对象与数据”：原始数据表按字段搜索、排序、分页、勾选全部筛选行、批量选回画布和导出筛选 CSV。每页 100 行；对象列表前 200 项，可搜索后续项。行映射必须显式声明，原始数据只读。
- “成组与对齐”：保存临时选择组、恢复选择、解组；独立文字/装饰边缘、中心和等间距对齐。框选后拖动支持 6 预览像素内吸附和辅助线，可关闭。不吸附数据点，不通过对齐改测量值。
- “查看此观测的原始数据”：真实 R/Python 行映射；未声明映射只显示捕获坐标。
- “添加随此观测移动的标签”：标签、点、误差关系保留；标签可独立调整字体/偏移，隐藏点时标签跟随。R 矩形、多边形和路径使用明确的 `data-fam-anchor`，不依赖圆点猜测。可为选中观测批量添加标签，每次最多 200 个。
- 多色标对象：分别设置各数值映射的色带、归一化、范围和标题，保留其他色标。
- 热图：反转、按均值或平均链接/欧氏距离排序，同方向单行色条与标签跟随；可显示与矩阵排序一致的行列树。聚类限最多 500 行/列，不插补缺失值。
- 网络：固定明确节点 ID 在源位置，或将当前展示位置保存为锚点后重排其他节点；边端点和标签跟随。不改原节点输入表。
- “投稿检查”：按最终物理尺寸检查字号、线宽、裁切、文字重叠、字体可能替换、白底对比度、灰阶颜色近似及嵌入位图实际 DPI。最小字号、线宽、DPI、最大图宽可配置，报告可下载。位图检查最多 30 个、文字重叠最多 600 条；字体、灰阶和几何提示需人工确认，不能替代目标期刊要求。屏幕预览按 CSS 96 DPI。
- “命名版本”：保存完整设置、分类显示外观/展示坐标/统计画法变化、并排预览、恢复版本。恢复可撤销，原代码与输入保留；最多 100 个命名版本，不代替最近 10 次会话撤销。
- “成组与对齐”：选择同类对象或同组观测；逐对象锁定；以首选对象或选择整体为对齐基准。方向键微移 1 像素、Shift 10 像素、Alt 0.1 像素。锁定限制直接编辑，必要的误差与标签跟随仍保留；图层继承外观仍可影响锁定对象。
- “外观预设”：保存、导入、导出、应用字体、字号、线宽、文字颜色、网格与边框。预设不含数据、拟合、坐标范围或逐点位移；应用可撤销，导入校验版本与数值。
- “操作影响”：区分外观修改、展示偏移和需重新计算的统计/画法；拟合仍以面板选择的原始或展示坐标为准。
- 原生画法：直角/圆形树、森林图效应区间文本列、双侧/左侧/右侧/交替半小提琴、地图区域插图。统计值与原始输入保留；半小提琴的统计横线与分布体使用同一侧。

## R 的显式观测接入

`bridge.R` 同目录必须保留 `bridge_semantic.R` 与 `ggplot_bridge.R`。`fam_save_semantic` 支持直角坐标及分面的 identity 点、柱、格子、线段和误差杆；多种点形保留。调用方声明原始 `rows`、唯一 ID 和需关联的图层，实际几何与未标记 SVG 对比校验，按 ID 绑定而非按绘图顺序匹配。不同图层可使用源表子集或重排行。最大 50,000 行；不支持直接把 stat 汇总结果、极坐标、重复或模糊 ID 当作原始观测。计算型图层应先在 R 中生成明确的结果表再绘制。随机位置变换需固定种子。

```r
source("bridge.R", encoding="UTF-8")
fam_save_semantic(p, "linked.svg", rows=d, id_column="sample_id",
  layers=list(list(layer=2, role="data"), list(layer=1, role="uncertainty")),
  x_column="x", y_column="value", group_column="group")
```

`fam_save_linked` 的旧调用仍可使用，内部委托上述协议。原始测量值存于行元数据；展示坐标为 `ggplot_build` 后坐标（例如对数变换），界面明确区分。仅修改展示位置不覆盖源表。Windows 在不兼容的 `C.UTF-8` locale 下可能无法 `source` 含中文的绝对路径，可在源码目录用相对路径，或先 `Sys.setlocale('LC_CTYPE', '.UTF-8')`；不修改用户系统 locale。R 原分析和原生统计重算仍在 R 中执行。

精确四语言矢量重放见 [language-export.md](language-export.md)。R/SVG 的显示联动不等于 Python 原生统计参数；不得声称所有 R 图已具备自动模型转换。

项目内 `examples/research-completion` 提供独立 CSV、5 张真实执行的 R 图和 7 张 Python 图；工作台项目为 `projects/research-completion-example`。它们导入原脚本，不调用模板 builder，示例数值仍是合成数据。

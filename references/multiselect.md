# 框选与多对象编辑 · v1.0 开发版

连续数值色带保持数值与颜色的映射，整图框选后统一纯色不会覆盖热图和色标梯度。改变连续配色使用“图例与色标”的色带选项；明确选中的离散观测仍可单独设色。

空白处按住左键拖出矩形；已有对象上先按住约 0.3 秒再拖动。快速拖动保留原来的单对象操作。开启“框选”时可以直接从任何对象开始画矩形。完整圈住目标图形；Shift 框选追加，Ctrl / Command 点击切换，Esc 清除。被区间遮盖的点按实际边界与命中面积识别，透明的编辑手柄不算额外对象。

右侧显示所选对象数量与简短列表。统一颜色、透明度、适用线宽；文字单独设置字体、字号、粗细、斜体；柱或箱体可统一自身宽度。空白数值框表示多个对象不一定同值，输入后统一。可以移除个别对象、清除或逐个编辑。统一设置仅修改当前选择；需要把颜色应用到整条系列时用逐个编辑中的所属系列选项。

框选默认包含所有可编辑的未锁定图层；“仅当前编辑层”可只选误差、标题等，避免误差杆包围的点一并入选。锁定层不能直接修改，但保留坐标框变化或数据移动带来的必要跟随。图例作为可拖动整体，普通刻度文字可单独选；箱线图的均值、中位数、须线与端帽分别识别。

整体拖动或输入预览像素位移时，误差与观测共用同一语义对象，不重复移动；柱子的原始重复点随父柱移动，选中父柱与重复点时只施加一次父位移。选中边框时移动其坐标区域，数据、误差与轴内文字随坐标映射重绘，避免把两条边框或点再移动一次。选中曲线与区间时按观测节点去重，绑定注释随原对象。三维点和显式绘图坐标不能从平面拖动猜测深度或尺度；字体与颜色仍可多选编辑。

组图可以跨子图框选；每个面板独立保存设置，来源图不回写。每次批量编辑生成一个撤销条目，保留本次打开的十步撤销与重做。关闭重开保留编辑结果；框选集合本身为临时状态。复位所选对象清除其独立覆盖，误差与数据层各自的修改保持分离；恢复整张原始图仍使用重置菜单中的对应功能。

多语言 SVG 的文本与图形支持框选与格式修改。若声明 `data-fam-entity` 和 `data-fam-follow`，整体位移按明确关系跟随；未声明的图形仍可独立编辑，不能由形状猜测原测量关系。位图只可作为整体参考层选择，内部文字和点仍需找回代码或重建。

普通打开保留轻量的前 2000 项关系列表；框选大量对象时按需读取完整关系并缓存，避免把未读取的点误当成整条系列。最多绘制 180 个细轮廓及总包围框，实际选择不受该显示上限影响。矩形与轮廓在画布的 HTML 层，不写入 SVG、PNG、PDF、TIFF 或复现脚本；拖出选框期间不持续请求服务器，提交位置才重新绘图。

位移以预览中的屏幕像素为准。各子图分别换算自身缩放，连续编辑从合并后的有效设置累加，保留来源图已有的位移。刻度、标题、普通图例及绑定色标明确声明所属坐标框；坐标框一同移动时，从属对象只跟随一次。使用画布坐标锚定的图例与文字保留其独立锚定方式。轴标题的位置从实际 SVG 绘制使用的 72 DPI 坐标读取，避免第一次移动跳位。

对数或倒序坐标下的展示移动按轴变换后的距离计算，误差杆、端帽、绑定文字及柱子的重复点保持同一屏幕位移。显式修改数据坐标仍使用数据单位的误差长度。通用 SVG 按语义对象真正父级的变换换算，声明了关系的观测与误差即使分属旋转、缩放不同的父级也各自换算展示位移。

单独框选色标时，选择中可能同时包含色标父组、颜色条、边框、数字和轴名。移动前按实际 SVG 父子关系去重：父组已移动时，内部对象只继承该位移，不再追加自身位移。独立框选数字仍可单独编辑位置；跨面板分别处理层级关系。测试必须包含“单独框选色标后用鼠标拖动”，整张图连同主轴一起移动不能替代这项检查。

界面左上角暂不显示图标，保留文字品牌。

Backspace 或 Delete 删除当前选中的单个/多个图形要素，保存为隐藏覆盖并支持一次撤销；观测行和来源捕获保留。输入框、文本域、下拉框、可编辑文字和弹窗中保留原键盘编辑行为，锁定对象不删除。连续长按不重复执行删除。

## 复制、剪切与粘贴

Ctrl / Command + C 复制、X 剪切、V 粘贴、D 重复所选单个或多个要素；右侧“更多编辑方式”提供同样操作。支持跨图与子图粘贴，保持物理字号和元素间相对位置；在原图内粘贴略微错开，重复粘贴继续错开。普通剪贴板文字可粘贴为新注释。Ctrl / Command + Z 撤销、Shift + Z 或 Y 重做，画布中 Ctrl / Command + A 全选、Esc 清除选择。每次剪切、粘贴或重复可一步撤销，新增要素保存在项目并进入矢量导出和复现代码。

数据点及其误差等从属要素一起复制为自由装饰副本；不复制观测身份，不增加统计样本，不参与拟合或相关分析。剪切原始观测只隐藏其展示，不删除来源行。副本保留来源对象记录及 display-copy-no-observations 标记。图例或多元素要素作为一个可编辑整体，分别复制的对象仍可分别编辑。

锁定对象不可剪切，注释层锁定或隐藏时禁止粘贴。输入框、文本域、下拉框、contenteditable 和弹窗中保留原键盘行为。系统剪贴板不可用时使用当前工作台内存剪贴板并提示，跨窗口复制需要系统剪贴板权限；不在用户未触发粘贴时读取剪贴板。

已选中对象的包围区域可直接拖动，包括没有图层标签的 R/SVG 文字；空白处拖动、对象长按后拖动和 Shift 仍可启动框选。按住 Alt 拖动临时跳过文字 / 装饰吸附，“更多编辑方式”可直接开启或关闭吸附；坐标与数据依然按原从属关系跟随。

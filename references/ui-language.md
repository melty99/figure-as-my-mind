# 工作台中英文切换

顶部原“原数据保护”按钮的位置改为语言按钮：中文界面显示 English，英文界面显示 中文；点击立即切换，并记住当前浏览器站点的偏好。新站点默认中文，无法访问浏览器存储时本次切换仍可使用；清除站点存储后回到中文。

仅切换软件界面，保持原始数据保护机制。图内 SVG / 数学文字、用户图件及项目名称、输入框内容、表格结果与源代码不自动翻译。导出绘图代码语言独立于界面语言。切换不调用保存 / 统计 / 绘图请求，不占撤销，弹窗草稿和编辑输入保留。窄窗口可使用原侧栏展开入口。

资源自带 assets/i18n.js 和 assets/locales/en.json，无联网翻译或外部依赖。运行时只本地读取语言包；原文本通过 WeakMap 保存以便还原，常用翻译缓存有上限，图内节点不参与扫描。动态界面在插入时翻译，内部选项值、对象 ID 与数据值保持。已有界面按中文标签查找 / 排序时应使用 famI18n.source / sourceAttr 保留内部身份；搜索可同时匹配中英文。未知扩展提示保留可追溯原文并通过词表组合翻译，新增功能应补充完整自然语句，不能依赖界面翻译改变统计方法。

原数据保护入口移除后，后台校验、data-protection.json、/api/data-protection 与投稿 / 代码包保护记录继续存在，不提供禁用原始数据保护的开关。

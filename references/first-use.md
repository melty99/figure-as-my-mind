# 第一次使用：界面入口与回归边界

工作台提供非阻塞、可收起的三步指引；收起状态仅保存于当前浏览器，使用帮助中可重新打开。空项目保持空白，用户明确选择导入或体验模板后才生成图件。重新打开已有项目保留保存设置，不进行初始化替换。

“导入图 / 数据”解释 SVG、CSV/TSV、参考图片和源代码的区别。源代码提示词可复制给 Codex，填写脚本和输入路径后沿用原语言接入；浏览器不会执行上传代码。SVG 成功后提示点选编辑，数据表成功后提示选择变量绘图，位图成功后提示找回源码或重建，不笼统声称导入图片即可逐项编辑。

常用编辑入口为全图、图形、文字、图例和坐标框，完整层列表仍可用。画布上方提示当前选择数量、取消选中和移动子图模式；未点击要素时不误报选中。图件名称用于打开，复选框用于组图/批量选择。设置搜索仅查当前层，切层自动清空；图件搜索和设置搜索均有清除/无结果反馈。

使用帮助按修改、组图、撤销找回和导出组织；快捷键在输入框中保留文字编辑行为。帮助和指引不创建绘图撤销、修改原始数据或写入导出 SVG。窄窗口保留保存状态，并可打开图件库/调整抽屉。

图件库顶部“查看范围 · Figure scope”让第一次使用时的列表保持可读：默认只看当前组图，需要跨组找来源时再选“全部图件与组图”，未组图单图可单独查看。它只是导航，不会删除、合并或重新保存任何图。桌面两侧内缘的分隔条可拖动、双击或按 Enter 重置；侧栏宽度只属于当前浏览器。

导出显示图件数量、实际毫米尺寸、图片背景与栅格像素；无勾选图时禁用勾选范围。PNG/TIFF 的 DPI 必须为 72–1200，空值及非法值在发起导出前定位输入并说明；SVG/PDF 不需 DPI，仅导出代码时禁用图片设置。保持所选语言与透明背景语义。源图中的位图不宣称变为矢量，矢量复现代码不宣称翻译了统计分析。

首次使用专项检查使用隔离的原 R/Python 示例副本和真正空项目，至少十个不同操作旅程。检查成功后的用户工作台仅允许 GET/HEAD；禁止测试写入用户项目。验证原始脚本/输入/捕获与全部既有设置、输出哈希。空项目启动的行为同时使用真正持久启动器回归，不只测试网页欢迎画面。

图库支持名称、中文 / 英文图型、boxplot 等常用别名和来源语言；组图同时按自身名称与所含图型匹配。首尾空白不影响搜索，Esc 清空搜索，图件数显示匹配数量 / 总量。仅组图命中时不显示空结果；搜索不清空已有勾选，也不产生绘图撤销。


## 批量复杂组图：逐张完成

项目有多张组图时，默认进入“逐张编辑组图”。上方显示第几组及完成进度；左侧只列出当前组的子图。选一张后，画布只绘制该子图，右侧修改的也是这张组图内的子图设置，来源单图和其他组保留。

1. 先选择子图精修。默认开启“本组联动修改”，以当前修改的子图为参考，将本次改变的兼容字体、坐标框实际宽高、图例格式和可匹配系列样式应用到本组其他未锁定子图。坐标范围、标签文字、统计方法和原始数据不随格式一起复制；无法匹配的系列明确跳过。
2. 需要保留例外时，在左侧勾选该子图的“锁定联动”。它仍可单独编辑，但不接收也不广播自动联动；解除锁定本身不会重新套用其他子图的旧设置。“锁定联动”与禁止移动的“锁定布局”是两个独立选项。
3. 点击“检查联动 · 调整组图”，才绘制当前整组，调整分布、间距与标注。可随时“返回子图编辑”，保留当前选择和修改。
4. 满意后点击“完成本组，进入下一组”。先保存成功，再标记完成并读取下一组；未应用的对象编辑草稿或保存失败会阻止进入下一组，修改保留。可回到上一组，重新打开项目也会保留进度。

一次联动操作整体撤销或重做，最多保留十次。撤销格式不会把进度跳回别的组图。完成过的组再次修改时会取消其完成标记。“退出逐张编辑 / 图件管理”可返回普通图件库，不自动将当前组标记完成。

Ctrl+S / Command+S 与顶部“保存项目”使用相同逻辑：右侧对象编辑栏打开时，应用并保存该对象当前草稿；无效参数保留在编辑栏中等待修正。普通对话框需先完成或关闭，再保存项目。保存失败会显示原因并保留未保存修改，避免将尚未应用的草稿误报为已保存。

# 精修与外观复用（v1.0 开发版）

右侧“更多编辑方式”集中复制粘贴、格式刷、同类 / 同组选择、找回隐藏要素、原图对照与快捷键说明，不额外增加常驻按钮。适用于已接入的 R / Python 原生图和通用 SVG；最终图沿用四语言矢量复现。

## 选择性格式刷

选择一个参考要素，“复制外观”或 Ctrl / Command + Alt + C；再选择单个 / 多个目标，“粘贴外观”或 Ctrl / Command + Alt + V。可勾选字体（含字号 / 粗细 / 斜体）、颜色、不透明度、适用线宽。文字参考默认只复制字体，保留不同组别配色。只复制适用的展示属性，不复制文字内容、坐标、原始数据、图型或统计模型。连续色带不被批量纯色覆盖，点与误差独立设色；原生字体字重与 SVG 数字字重分别转换。字号按物理 pt 读取，在 SVG / 不同缩放子图间换算。一整次应用只占一次撤销。

外观缓冲保留在当前窗口，独立于系统图形剪贴板；重新打开后，已经应用的格式继续保存在项目。未知 SVG 的混合组件仍按其声明的整体编辑；需要只改变内部文字 / 线段时，选择具体组件。

## 键盘微调与选择

在画布上选择单个或多个要素，方向键移动 1 预览像素，Shift 为 10，Alt 为 0.1。二维观测的误差、端帽和绑定文字使用与鼠标相同的联动机制，不改原始观测。“更多编辑方式”可直接开关文字 / 装饰吸附；按住 Alt 拖动临时跳过吸附。已框选的 R/SVG 对象支持在包围区域直接拖动。一次连续按键合并提交并占一次撤销，轮廓提供轻量预览；三维 / 显式数据坐标仍由其专用面板调整。输入框、弹窗与锁定对象保留既有行为。

“选择所有同类要素”从单选也可使用，按图层、语义类型、箱线组件角色和 SVG 图形类型匹配，避免把中位数与须线、文字与圆形混选。“选择观测所属分组”要求显式系列身份；未知分组不会按颜色猜测。

## 找回隐藏要素

删除 / 剪切保留为隐藏覆盖。“找回隐藏要素”按文字、对象 ID 和图层搜索；全选匹配、恢复部分或全部未锁定对象。支持观测、标题 / 数字、拟合注释及隐藏图层，恢复显示保留原颜色、文字、位移和原始数据，可一步撤销。组图只修改当前子图并覆盖其来源图的隐藏设置，不回写来源单图。锁定对象和图层需要先解锁。

原脚本本来未画出或不显示的元素不当成此次删除的对象。隐藏整层时，恢复单个要素不能越过该层隐藏；需同时恢复所属图层。

## 对照原始图与复位

“对照原始图”并排展示当前数据版本的捕获初态与当前编辑结果，显示各自真实毫米尺寸并提供同步预览缩放与滚动；不替换项目、不占撤销次数。组合图对照当前子图。更早的数据版本通过命名版本 / 历史恢复，不将当前数据的初态误称为最早数据版本。

复制的复合 SVG 对象复位保留其矢量内容与来源记录，恢复到粘贴时外观与位置，同时清除未锁定内部组件的独立覆盖；粘贴的纯文字保留初始内容与位置。复位不把数据副本变为观测，来源哈希与样本数保持。

没有声明坐标角色的 R/SVG 文本可直接点选 / 拖动，自动进入自由文字编辑；锁定注释层时仍拒绝直接修改。明确声明了数据 / 图层关系的要素继续使用其专用联动模式。


## 双击散点外观

双击实际点形打开“编辑散点外观”，默认仅当前点。支持常用颜色与自定义颜色、边线色、0–1 不透明度、实心/空心、已接入点形和 0.05–20 的直径倍数。大小倍数基于当前来源系列的原点大小，保留气泡面积编码的相对关系。选择同系列后，只提交用户实际修改的属性；已有不同颜色和点形不会因仅改大小而被统一。已锁定对象拒绝整组提交。误差线外观与原始数据不受影响，组图只改双击的子图。草稿取消不保存，一次应用占一次撤销，重开保留。R/SVG 点形必须显式声明 point glyph 和 anchor；未知矢量对象不猜测为观测点。


### 无色与散点边线

所有颜色控件采用共享色板、可输入颜色值与常用颜色菜单，菜单提供“透明 / 无色”，存为 none。仅移除对应填充、边线或文字的着色，原始数据保持。渐变节点和分级区间的 none 解析为透明色，不改变数值范围；不透明度保留独立调节。散点弹窗可选择仅当前点、同系列、本轴全部或当前子图全部点；选择颜色即使与当前点相同，也能应用至范围内其他点，只统一明确编辑的属性。独立边线色最后应用，避免填充色覆盖；点边线粗细可为 0–30 pt，原宽度为 0 时选择可见边线色自动恢复 0.75 pt（显式输入 0 时保持无边线）。一次应用占一次撤销；取消不保存，锁定对象拒绝整个提交。


### 外观修改一致性

图例主动重新选择同色时可重新统一关联系列；仅改变范围不会覆盖其他属性。复杂图例组件的边线与粗细采用与数据点相同的独立设置顺序。空心点可直接恢复实心。框选批改按当前子图已保存的样式顺序提交，不依赖系统时钟；组图分别排序。箱线细节返回真实的无色状态与点尺寸。透明 SVG 渐变节点和分级色标重新打开时优先读取已保存的颜色草稿语义，选择可见色后不残留由无色转换产生的零透明度。

## 双击文字格式

双击标题、轴标题、刻度、图例文字、注释及子图标注，打开字体 / 字号 / 粗细 / 斜体 / 颜色 / 不透明度草稿弹窗。已识别的刻度文字默认选择同一条轴全部刻度（含离散分类标签），其他文字默认单个；仍可显式选择单个、同一图例文字或当前子图全部文字。只应用实际修改的属性，取消不保存，一次应用一次撤销。图例符号与空白保留配色入口，坐标轴空白保留范围入口。普通 SVG 的真实 text 可编辑，转曲轮廓仍需替换成文本。


## 双击对象的完整参数草稿

双击弹窗的“位置、排列与全部相关参数”直接复用当前对象适用的右侧参数，分类切换和搜索无需离开弹窗。字体等重复设置集中在上部，避免不同入口覆盖冲突。标题可修改内容、左右 / 居中锚点、基线、字号、字词间距、旋转、显示偏移及所属坐标系的位置；自由 SVG 多行文字另支持行距。内容 / 位置只改当前文字；同轴刻度的旋转按范围统一应用，其他文字的旋转仅当前；字体 / 颜色 / 对齐 / 间距按明示范围；刻度数值和计算生成的公式内容只读。子图 a / b 标注独立保存位置、对齐、旋转与格式。

分类图例可设置横竖排列、填充顺序、列数、条目顺序、符号方向、文字与符号的独立位移、行列间距、整体缩放及边框；色标包含渐变 / 分级配色及适用的尺寸、位置、轴名、刻度、映射范围、归一化。散点包含明确的应用范围及适用的系列、画法、拟合与误差参数；可识别的柱、箱、扇区和自由 SVG 形状也有双击入口。轴范围弹窗可切换到坐标框、四边框、轴名、刻度、网格与标题设置。只显示接入后具有明确含义的参数，普通 SVG 不增加未知的统计重算。

所有参数在隔离的当前图 / 组图草稿中操作，不发送保存请求、不新增撤销记录。应用把上部常用外观与完整参数一起提交为一次修改；取消、Esc 和关闭丢弃草稿。编辑仅作用于当前图或当前组图面板，不回写来源图与原始数据。删除 / 新建对象、改用其他面板及外部操作通过原工作流完成，避免弹窗草稿执行另一项任务。


### 同轴刻度与独立旋转角度

双击已识别的 X / Y / Z 轴刻度默认选择同一条轴的全部刻度，分类字符串与数字刻度一致。原生 Matplotlib 的同轴字体、字号、字形、颜色与角度保存到相应轴设置，清除与本次属性冲突的已有单标签覆盖；范围改变生成新刻度时仍沿用轴设置。其他轴、轴标题及其他子图不跟随。普通未声明坐标角色的 SVG 文字不按位置猜测为刻度。

“字形样式（正体 / 斜体）”控制字形；上部独立的“文字旋转（度）”支持 −360 至 360、手动小数及常用角度。刻度角度为绝对方向，正值逆时针、负值顺时针；同轴批改围绕各自刻度锚点旋转，反复修改不累加。选择“仅当前文字”仍可精修单个标签；后续同轴批改可统一清除本次属性的旧单标签覆盖。一次应用一次撤销，取消不保存，刻度内容和原始数据只读。


## 停靠编辑与实时预览

双击编辑器固定占用右侧原调整栏；左侧图件库不隐藏，桌面绘图区的大小和位置保持。仅普通调整栏暂时由当前对象编辑器替换。窄窗口按上下区域显示图与编辑器。文字、散点、图例配色 / 渐变、坐标轴范围和详细图形参数使用同一个草稿事务。输入后约 180 ms 防抖，仅保留一个预览请求和最新待处理值，后台通过 `/api/object-preview` 校验展示设置并渲染 SVG，不写项目、来源、历史或撤销。预览结果不覆盖底层对象 DOM，保留文字锚点与选定范围；无效输入保留最后有效预览并提示原因。

点击“应用”一起保存并占一次撤销；取消、关闭或 Esc 丢弃草稿并恢复原图。草稿期间其他项目编辑入口暂不可用，避免把预览当成已保存结果。预览不重新运行 R / MATLAB / C 源码。

## 饼图与扇区大小

在数据层选中扇区或双击扇区，设置“扇区缩放范围”和“所选扇区大小（%）”。仅当前扇区改变其半径及对应标签位置；框选多个扇区后右侧提供统一大小；同一饼图全部扇区被选中时按原图基准整体缩放，包括分离位置和标签。单个 / 部分扇区的半径倍数作用于当前整体大小的基础上。也可直接设置“饼图整体大小（%）”，统一清除各扇区额外半径覆盖。范围为 10%–300%，整图和局部保存到 `native.plotVariants[axis].pieScale` 与 `native.entities[id].wedgeScale`。

原始数值、扇区角度、标签文字和字号不变；环形图保留内外半径比例，独立图例不跟着变大。图层和所选对象锁定继续生效；分组编辑只改当前子图。超过绘图区时可调小或调整容器，系统不会改变数据或自动改扇区角度来凑版面。该语义半径功能适用于已识别的原生扇区；普通 SVG 沿用其真实形状变换控件。

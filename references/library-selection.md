# 图件库多选与删除 · v1.0 开发版

左侧单图与组图均可勾选。全选当前列表只作用于当前搜索结果；取消勾选清除整套选择。Shift 连选、Ctrl / Cmd 点击加选、空格切换勾选；在图件库中 Ctrl / Cmd+A 全选，Delete / Backspace 打开删除确认。编辑搜索文字时这些删除键仍正常编辑文字，画布对象快捷键保留在画布范围内。

“删除所选”处理全部勾选项，包括筛选外的项，提示注明筛选外数量，确认框列出全部名称。每行的 × 删除该项。删除进入“已删除图件”，一次批量删除占一次撤销，也可从已删除列表选择或全选恢复。删除当前项自动选择下一个可用项；全部删除清空画布，恢复一项时自动显示其原图。

删除为项目记录上的 `libraryDeleted: true`，原源代码、数据、捕获文件与已有导出保持，组图引用和子图设置保留。被删除的原图仍可供已有组图渲染；删除组图不影响单图。恢复移除此标记，保留删除前的全部样式及对象修改。保存 / 重开 / 最近十次撤销均包含此标记。源记录保留，因此重开后恢复无需接受未经注册的源码路径。

普通图件列表、数量、全选、全部导出与默认 `reproduce.py` 排除已删除的顶层项；组图渲染仍解析其保留的源记录，显式指定已删除 ID 的重放可用于审计。选择组图可批量删除及导出；创建新组图与“应用当前样式到勾选图件”仍使用所选单图。

删除只改变图件库状态，不覆盖原始统计数据，不重新执行 R / Python / MATLAB / C 分析代码。清理磁盘文件不属于此删除操作。

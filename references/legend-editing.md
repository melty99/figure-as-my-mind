# 图例内部编辑（v1.0 开发版）

在“图例与色标”层选择当前坐标区域与图例条目。颜色联动以捕获的条目身份为依据，不因排序、标签改名或移动而改变。重复同名 / 无关联的图例不猜测数据系列。

## 鼠标与排版

- “整体图例”继续从内部任意可见内容或空白处拖动整组。
- “单个条目”移动该条目的全部符号与文字，保持相同位移。
- “内部精修”点击文字只拖文字，点击组合符号里的某个组件只拖该组件；空白处可移动条目，图例标题可独立拖动。
- “当前条目的文字 / 全部符号”限制拖动目标，适用于细小或相互遮挡的组件。
- 横排、竖排、多列、先填行 / 先填列，以及提前、后移和反转顺序控制常规排版。
- 符号可以位于文字左、右、上或下，也能为单条目单独选择。字体、字号、粗细、斜体与文字颜色按条目编辑。
- 位移采用图内 pt：右 / 下为正，界面缩放或组图容器缩放后仍按本地坐标保存。支持条目、全部符号及单组件旋转 / 缩放。
- “图例边框适配移动后的内容”按实际组件范围更新已显示的边框；边框显示开关独立。组件允许自由重叠，不强行纠正用户排版。

一次拖动占一次撤销，鼠标离开画布后仍保留拖动捕获；取消操作恢复已保存显示。内部精修中“复位当前对象”恢复所选条目 / 文字 / 符号 / 组件的几何，不清空整张图例；“复位当前条目的位置与变形”恢复当前条目及其组件几何，保留颜色和字体。整体模式仍复位整张图例。所有修改随项目保存，组图只改当前面板。

## 参数

`native.legends[axis]`：

- `arrangement`: horizontal / vertical / grid。
- `ncols`、`fillOrder`: grid 列数与 column / row 填充。
- `entryOrder`: 捕获条目的完整索引排列，每个索引出现一次。
- `symbolSide`: original / left / right / top / bottom。
- `handleTextPad`: 符号与文字间距，以共同字号为单位。
- `titleOffset: [x,y]`、`fitFrame`。
- `entries[index]`: `label`、`fontFamily`、`fontSize`、`fontWeight`、`fontStyle`、`textColor`、`symbolSide`、`offset`、`textOffset`、`symbolOffset`、`rotation`、`scale`、`symbolRotation`、`symbolScale`。
- `entries[index].parts[component]`: `offset`、`rotation`、`scale`、`color`、`alpha`、`lineWidth`。

文字 / 符号 / 组件的颜色保留既有样式优先级。手动组件颜色优先于同条目共同符号颜色；重新整体统一系列颜色时，需先清除有意保留的组件单独颜色。

## 实现与接入

普通 Matplotlib 轴图例复用捕获的 DrawingArea、TextArea 与复杂 handler 输出，不重新创建代理符号。稳定索引不随视觉顺序改变。位置和自由变形在图例 SVG 的独立语义组上应用，因此 SVG / PNG / PDF / TIFF 及 `reproduce.py` 重放一致；直接调用 `apply_fam_style` 后自行 `savefig` 支持常规排列与字体，不能替代本编辑器对 SVG 内部自由变形的完整重放。

任意导入 SVG 的文字和图形仍可通过“自由装饰编辑”逐对象移动、变形和改样式；语义未知时不承诺自动识别图例条目及对应数据。特殊自定义 OffsetBox 结构、Figure 级或额外独立图例需要源码适配或 SVG 对象编辑，不将多个主图例强行合并。连续色标仍使用原有数值映射与色标参数，不能按分类符号重排颜色数值。


## 双击配色编辑

双击图例中的实际文字优先打开文字格式弹窗，单独选择字体、字号、粗细和斜体；双击符号或空白继续打开本节配色编辑。

双击实际图例符号 / 空白或色标打开草稿弹窗，按颜色映射选择界面：

- 分类图例：逐条修改符号颜色、不透明度、文字颜色，常用颜色可直接选择。存在唯一语义系列时默认联动其数据图形；可关闭联动只改符号。复杂代理符号没有唯一数据对应时只改图例，不按标签相同或颜色相近猜测。
- 连续色标：预设色带、自定义 2–32 个颜色节点、节点位置及不透明度、反转与即时梯度预览。位置是当前范围内的 0–1 比例，首尾为 0 和 1；范围、归一化和原始标量数组保持。范围、对数 / 中心归一化仍在右侧“图例与色标”层调整。
- 分级色标（BoundaryNorm）：按实际数值区间逐色编辑或反转区间配色，不改变边界和分类。换预设时保留原色标的颜色数量，避免区间都落到新色带的一小段。
- SVG 的实际 linearGradient / radialGradient：双击使用该渐变的图形，编辑定义中的颜色节点；共享同一渐变定义的对象一起更新。适用于任何源语言输出的这种 SVG。只有图片像素、栅格色条或没有语义关联的 SVG，不能据此猜测数值颜色映射；需先用原语言源码 / 明确映射接入。

弹窗内修改不渲染整张图或写项目，点击“应用颜色”后一次保存并占一次撤销；取消、关闭或 Escape 丢弃草稿。位置重复、缺失、非有限或透明度越界时保留弹窗并指出问题。遵守数据层和图例层锁定；组图只修改双击所在的子图，即使画布布局已锁定也能编辑内部。

`native.mappables[id]` 新增 `cmapStops: [{position,color,alpha}]`、`cmapReverse: bool`、`colorBins: [{color,alpha}]`。改回预设时显式设 `cmapStops: null`、`colorBins: null`，避免继承的自定义设置覆盖预设。原图全局 `native.cmap` 等仍兼容。每个色标按自身真实 mappable 身份关联；多个色标共享一个映射时会一起更新。

SVG 保存为 `overrides[gradientId].gradientStops`，不覆盖原 SVG。预览、高质量导出和重放使用同一渲染路径。


## 图例整体缩放

在“图例与色标”层，分类图例显示四角和四边共八个蓝色手柄。拖动等比例缩放，固定对侧边 / 对角；文字、符号、间距与边框统一变化，圆形点和字体比例保持。右侧“图例整体缩放（%）”可输入 5%–2000%，数值调整保持可见中心，恢复为 100% 保留字号、颜色和内部排版。改变排列方向、列数或间距可分别调整宽高。连续色标保留原来的八向宽度 / 长度手柄。

拖动期间只变换前端 SVG，不请求整图重渲染；松开一次提交并占一次撤销，Escape / 指针取消恢复原显示。组图仅修改当前子图，布局锁定仍允许内部图例缩放；图例层或图例对象锁定时不显示缩放手柄。

使用 `native.legends[axis].scale` 和 `scaleOffset: [x,y]`，位移以本地图内 pt 保存。整体变换嵌套在图例语义组内部，中心随原生图例位置更新；因此之后整体移动、框选多对象移动和内部文字 / 符号精修仍采用一致的屏幕位移。原字体、分组颜色、误差数据及统计值保留。SVG / PNG / PDF 导出与项目重放使用同一变换。


### 无色与散点边线

所有颜色控件采用共享色板、可输入颜色值与常用颜色菜单，菜单提供“透明 / 无色”，存为 none。仅移除对应填充、边线或文字的着色，原始数据保持。渐变节点和分级区间的 none 解析为透明色，不改变数值范围；不透明度保留独立调节。散点弹窗可选择仅当前点、同系列、本轴全部或当前子图全部点；选择颜色即使与当前点相同，也能应用至范围内其他点，只统一明确编辑的属性。独立边线色最后应用，避免填充色覆盖；点边线粗细可为 0–30 pt，原宽度为 0 时选择可见边线色自动恢复 0.75 pt（显式输入 0 时保持无边线）。一次应用占一次撤销；取消不保存，锁定对象拒绝整个提交。

### 单图与组图移动模式

“移动子图”只对组图生效。切回单图时，即使旧项目保留 panelMoveMode=true，也不得隐藏图例缩放手柄。切换到文字、图例、坐标框等非画布编辑层时，同时退出此前的子图移动模式；组图的实际移动模式仍不显示重叠的内部缩放手柄。


SVG 渐变沿用原节点范围，允许首尾位于 0 / 1 内部以及同位置节点形成的突变色阶；双击后可改各节点位置、颜色和透明度，最多 256 节点。保留节点顺序、渐变继承引用和原输入，修改一次应用、一次撤销。原生数值色带继续使用 2–32 个严格递增且首尾为 0 / 1 的节点，不更改数值范围或观测。

SVG 节点的实际不透明度同时计入 stop-color 中的 alpha 与 stop-opacity；仅修改其他节点时保留这一组合结果，不把半透明节点变成实色。

现代 SVG 的 color(srgb …) 等颜色交给浏览器转换为 sRGB，颜色与 alpha 分开保存。编辑器共用一个 1×1 色彩转换画布，避免为每个渐变节点创建画布。

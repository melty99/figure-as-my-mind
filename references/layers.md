# 分层编辑与必要联动（v1.0 开发版）

默认选择一个编辑层：数据与图形、误差与区间、坐标框、刻度与网格、注释与标题、图例与色标、画布与组图。界面只提供当前层的直接调整，其他层仍执行已声明的依赖关系。锁定禁止直接修改；隐藏改变显示，均保存在 `native.layers`。隐藏数据层时同时隐藏对应误差、绑定标签和图例/色标。全图格式入口保留全部高级参数；存在锁定层时先解锁再统一格式。

| 主对象变动 | 必须跟随的要素 | 保持的基线 |
|---|---|---|
| 观测点展示位移 | X/Y 误差杆、端帽、绑定标签、注释箭头锚点、同一曲线节点 | 原始输入及捕获快照 |
| 柱形分类方向与组内间距 | 同类别对称系列、所属系列全部类别及其误差/端帽 | 柱高、数值末端、基线与原数据 |
| 有唯一所属关系的置信带曲线节点 | 该 X 对应的上下边界 | 其他节点与区间 |
| 已接入的竖向 / 横向 / 凹口箱体位移与宽度 | 须线、端帽、均值、中位数与样本点随位置；线宽方向按箱宽变化 | 其他箱体；点值不随箱宽修改 |
| 饼图扇区展示位移 | 该扇区分类文字和百分数文字 | 原始构成值 |
| 模板系统发育树共享节点 | 所有相接折线顶点 | 源 Newick 与枝长 |
| 坐标框平移/缩放、范围、轴尺度 | 数据、误差、数据坐标注释、网格、色标相对位置 | 原始坐标；框/画布坐标文字沿其自身变换 |
| 数据系列颜色/点形/点尺寸 | 图例代理符号 | 数据和计算结果 |
| 画布或组图面板尺寸 | 坐标映射与面板渲染 | 原生字号、线宽的物理 pt |

直接拖动数据控制点、坐标框内部及四边四角手柄时，浏览器调用 `/api/preview` 从原生对象重建临时图；预览不写文件、不增 revision。松开鼠标后只提交一次可撤销的设置，最终导出没有编辑手柄。坐标框模式可从内部任意位置拖动；四边四角手柄保持固定屏幕尺寸。固定比例图缩放时联动宽高并保持对边或对角，防止地图或饼图被拉伸。最多列出 2000 个语义对象，画布显示前 500 个二维控制点；大量对象可按 `native.seriesMoves` 或由 Codex 按索引批量设置。

## 坐标与可复现性

`native.entities` 以 `artist-id::p索引` 标识观测。默认 `dx`、`dy` 是轴宽高的比例，在轴自身的线性/对数/symlog 变换中解析；反向轴仍符合屏幕方向，改变物理框尺寸不会改动已解析坐标。`mode=coordinates,value=[x,y,z]` 是显式绘图坐标覆盖，原始坐标仍显示并保留。三维不从二维拖动猜 Z，只能输入 XYZ；相机在坐标框层的 3D 面板。旧 `barValue` 展示覆盖保留用于已有项目复现；新交互不提供数值末端改写。统计对象分类方向限制见 interaction-safety.md。`errorScaleX/Y` 在当前中心两侧缩放各自误差，保留非对称性。这些编辑不是原始测量值的修改，也不自动重新拟合模型。

Matplotlib 依据 ErrorbarContainer/BarContainer 的所属结构绑定点、区间和帽；`scatter + errorbar(fmt='none')` 只在中心唯一时匹配。Annotation 的数据锚点跟随，offset-points 文字保持相对偏移。`native.bindings=[{entity,artist,index}]` 可绑定数据坐标文字或 LineCollection 的指定误差段；框/画布文字不能强行当数据坐标处理。多对象重叠、曲线归属不唯一、三维误差杆深度关系、非标准箱线图和自定义图型须由原绘图代码提供适配，不猜统计含义。推断失败会在面板中列出提示。

回归、PCA、插值场等计算依赖需在原语言代码中显式声明并重新运行；展示位移不会虚构统计结果。要更新测量数据，先生成新的数据/源码版本重新计算、重新导入，再按角色应用格式。批量默认只传格式，不自动复制观测坐标或依赖绑定到其他变量。

旧项目自由 SVG 覆盖继续保留。旧几何偏移不自动解释成数据变动；若旧覆盖已独立挪动观测，先核对并复位该覆盖，再采用联动控制。自由模式供独立装饰对象使用；带数据/误差/框语义的对象不能通过此模式拖离关联关系。

“自由装饰编辑”可直接新增文字、箭头、矩形、圆，选择被遮挡的对象，改常用颜色、透明度、字体和具体几何尺寸。右下角手柄按对象中心等比例缩放，上方手柄绕中心旋转；坐标/角度/缩放输入可精确调整。新增装饰自动打开此面板；在注释层选中独立装饰也打开同一面板，避免误改坐标区标题。当前对象和框选对象复位保留新增对象并清除独立修改；恢复整张原始图仍删除新增装饰。

导入 SVG 中未声明数据关系的独立图形可以直接拖动；不能因其缺少图层标记而当成画布空白。自由编辑只检查目标层的锁定，其他层锁定不妨碍独立装饰。已声明的观测、从属和坐标框继续走联动编辑；实际数据变化需原语言适配。对象自己的颜色与透明度优先于注释层默认外观。缩放/旋转手柄在 HTML 编辑层，导出与复现不包含手柄。

## 任意绘图语言的 SVG 协议

保留原语言代码并导出 SVG。每个观测声明一个唯一的 owner ID 和实体名，从属对象明确声明实体名，嵌套从属不会重复位移：

```xml
<g id="observation" data-fam-layer="data" data-fam-entity="obs-1">
  <circle cx="100" cy="140" r="5"/>
</g>
<g id="interval" data-fam-layer="uncertainty" data-fam-follow="obs-1">…</g>
<text id="label" data-fam-layer="annotation" data-fam-follow="obs-1">…</text>
```

通用 SVG 位移是 viewBox 宽高的比例，没有自动的数据坐标/轴尺度映射；轴范围、真实三维、重新计算区间或特殊几何须调用原代码适配。未声明关系的 SVG 可编辑格式，但不能承诺自动联动；位图须重建语义对象。协议允许接入任意绘图语言，不代表无需适配就能准确识别所有图型。R/svglite 桥接需实际 R 环境验证。

实现依据：Matplotlib [ErrorbarContainer](https://github.com/matplotlib/matplotlib/blob/main/lib/matplotlib/container.py) 与 [坐标变换文档](https://matplotlib.org/stable/tutorials/advanced/transforms_tutorial.html)。在 Matplotlib 3.10.8 上用 `scripts/linked_qa.py --round 1..5` 的隔离项目验证真实拖动、几何、锁定、重开、组图与导出。
